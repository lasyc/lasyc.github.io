注释

为什么要有注释

注释就是对代码进行解释说明的文字。通过注释，可以快速了解一个程序的功能和实现思路，提高代码的可读性。

注释分类

  1. 单行注释：// 注释内容
  2. 多行注释：/* 注释内容 */
  3. 文档注释：/** 注释内容 */

代码示例

注意事项

  1. 注释不会影响程序的运行，编译器在编译时会自动忽略注释内容；被注释掉的代码同样不会被执行。
  2. 多行注释不能嵌套使用：遇到第一个 */ 注释就结束了，嵌套会直接导致语法错误。
  3. 文档注释可以被 javadoc 工具提取，用于自动生成 API 文档，写工具类、类库时养成写文档注释的习惯很有价值。

关键字

什么是关键字

关键字（keyword）是 Java 中已被赋予特殊含义、有固定用途的单词，例如：class、public、for、if 等。它们已被语言本身占用，不能用作类名、变量名等标识符。

补充：goto、const 是 Java 的保留字，目前虽未使用，但也禁止用作标识符。

关键字 class

class 用于创建或定义一个 类。被 class 修饰的名字称为 类名。

字面量

什么是字面量

字面量是指在代码中直接表示的固定值，例如：数字、字符、字符串等，如 100、'A'、"Hello"。

变量-基本用法

什么是变量

变量是程序运行过程中值会发生变化的量。变量可以用来存储数据，并在程序中随时读取和修改。

变量本质上是内存中的一个存储空间，程序通过变量名来访问它。

变量命名规则

  • 变量名由字母、数字、下划线和美元符号组成
  • 不能以数字开头
  • 不能使用 Java 关键字
  • 命名尽量做到见名知意

变量的定义格式

变量-使用方式和注意事项

使用方式

  • 读取变量的值：直接写变量名即可，如 System.out.println(age); 会打印出 age 当前的值
  • 变量可以参与计算，如 int nextYearAge = age + 1;
  • 修改值：对变量重新赋值即可，如 age = 30;。注意：变量只能定义一次，但可以反复重新赋值

  3. 一条语句可以定义多个变量
  4. 变量在使用前必须赋值

计算机中的数据存储

在计算机中，任意数据（数字、文字、图片、声音等）最终都是以二进制（0 和 1）的形式存储的。之所以选用二进制，是因为电子元件天然只有”开/关”两种稳定状态，用 0/1 表示最可靠也最易实现。

进制

进制 说明 值 书写格式
十进制 满十进一 0 ~ 9 无
二进制 满二进一 0、1 0b 开头
八进制 满八进一 0 ~ 7 0 开头
十六进制 满十六进一 0 ~ 9、A ~ F 0x 开头

Java 源码中直接书写的数字默认是十进制；想用其他进制表示，需要加对应前缀，例如 0b1010（二进制，值为 10）、017（八进制，值为 15）、0x1F（十六进制，值为 31）。

进制之间的转换

其他进制转十进制

  • 二进制转十进制：从右到左，每一位乘以 2 的对应次幂再求和，例如二进制 1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11
  • 八进制转十进制：从右到左，依次乘以 8 的权次幂，然后求和
  • 十六进制转十进制：从右到左，依次乘以 16 的权次幂，然后求和
  • 十进制转二进制：不断除以 2 并记录余数，直到商为 0，最后把余数倒序排列，例如 11 ÷ 2 的余数依次为 1、1、0、1，倒序后即得 1011

十进制转其他进制

  • 十进制转二进制：不断地将十进制数除以 2，记录下余数，直到商为 0，然后将余数倒序排列
  • 十进制转八进制：不断地将十进制数除以 8，记录下余数，直到商为 0，然后将余数倒序排列
  • 十进制转十六进制：不断地将十进制数除以 16，记录下余数，直到商为 0，然后将余数倒序排列

字符编码（ASCII / Unicode / UTF-8）

计算机底层只认识 0 和 1，那么字符（如 ‘A’、’中’）是如何存储的？思路是：给每个字符分配一个唯一的编号（码点），存储时完成”字符 → 编号 → 二进制”的转换。

  • ASCII：最早的字符编码，用 7 位二进制表示，共 128 个字符，包含英文字母、数字和常用符号。例如字符 a 的编号是十进制 97，对应二进制 0110 0001。ASCII 中没有汉字
  • GB2312 / GBK / BIG5：因为 ASCII 没有汉字，中国制定了 GB2312（简体中文）等本地码表，之后又扩展为 GBK，收录了中日韩等大量汉字；我国台湾地区则使用 BIG5 记录繁体中文
  • Unicode：为全世界几乎所有语言的字符统一编号，Java 的 char、String 底层就是基于 Unicode 设计的
  • UTF-8：Unicode 只是”编号表”，还需要约定如何存储，UTF-8 就是最常用的一种变长编码：按编号大小用 1~4 个字节存储，完全兼容 ASCII，是目前网页、文件、数据库等场景的事实标准。例如汉字”中”在 UTF-8 下占用 3 个字节

补充：Unicode 规定前 128 个字符的编号与 ASCII 完全一致，所以字符 a 的编号 97 在 ASCII 与 Unicode 中相同。

数据类型

数据类型的分类

基本数据类型

数据类型 关键字 字节(byte) 位(bit) 取值范围
整数 byte 1 8 -2^(8-1) ~ 2^(8-1)-1
整数 short 2 16 -2^(16-1) ~ 2^(16-1)-1
整数 int 4 32 -2^(32-1) ~ 2^(32-1)-1
整数 long 8 64 -2^(64-1) ~ 2^(64-1)-1
浮点数 float 4 32 -3.401298e-38 ~ 3.402823e+38（这里指绝对值范围）
浮点数 double 8 64 -4.9000000e-324 ~ 1.797693e+308
字符 char 2 16 0 ~ 2^16-1
布尔 boolean 1 8 true、false

注意事项

  1. 直接书写的整数默认是 int 类型，小数默认是 double 类型
  2. 定义 long 类型的变量，值后面要加 L（推荐大写，避免与数字 1 混淆），如：long num = 123456L;
  3. 定义 float 类型的变量，值后面要加 F，如：float num = 3.14F;
  4. 只比较”能表示的数值范围”：double > float > long > int > short > byte。注意 float 虽只有 4 字节，但它采用指数形式存储，能表示的范围反而远大于 8 字节的 long（代价是精度有限，后面会讲到）
  5. 上表中 float/double 的取值范围指的是”绝对值范围”：以 float 为例，它还能表示 -3.4e38 ~ -1.4e-45 之间的负数以及 0；boolean 只表示 true/false，不参与数值比较

标识符

什么是标识符

标识符是程序中用来表示变量、函数、类等的名称

命名规则

  1. 由字母、数字、下划线(_)和美元符号($)组成，但不能以数字开头
  2. 区分大小写
  3. 不能使用 Java 的关键字和保留字
  4. 变量名或方法名常采用小驼峰命名法，如：studentName、getStudentName
  5. 类名常采用大驼峰命名法，如：Student、GirlFriend
  6. 命名时应见名知其意，如：age = 18、name = "张三"，而不是 a = 18、b = "张三"

键盘录入

使用Scanner类进行键盘录入

使用步骤

  1. 导包：import java.util.Scanner;（写在类定义之前）
  2. 创建 Scanner 对象：Scanner scanner = new Scanner(System.in);（System.in 表示键盘输入）
  3. 读取输入：读取整数用 scanner.nextInt()，读取小数用 scanner.nextDouble()，读取整行字符串用 scanner.nextLine()
  4. 使用完毕关闭：scanner.close();

注意事项：

  • nextInt() 等按空格分隔的方法与按回车结束的 nextLine() 混用时，可能出现”明明输入了却读不到内容”的现象（残留的换行符被 nextLine() 直接读掉了）。初学阶段建议统一使用 nextLine() 读取后再手动转换为需要的类型
  • 输入内容与期望类型不符时（如要求整数却输入了字母），会抛出 InputMismatchException 异常导致程序中断，实际开发中需对输入做校验
  • 关闭 Scanner 会连带关闭底层的 System.in，如果后面还要继续读取输入，就不要提前关闭

AI 工具和 IDEA 的相关设置

界面与字体

File → Settings（Windows）或 IntelliJ IDEA → Preferences（macOS）→ Editor → Font，可调整编辑区字体与字号；按住 Ctrl 滚动鼠标滚轮可快速缩放字号。

AI 工具
