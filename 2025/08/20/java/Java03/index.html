隐式转换和强制转换

拓展：“+” 的用法

数字相加

两数相加时，若数据类型不一致，需要先统一数据类型，这就需要类型转换

类型转换的分类

  1. 隐式转换：取值范围小的类型自动转换为取值范围大的类型，无需我们干预，由编译器完成
  2. 强制转换：取值范围大的类型手动转换为取值范围小的类型，需要显式书写，且可能丢失精度或溢出
  3. 常见”容量”顺序：byte < short < int < long < float < double（float 数值范围大于 long，故可隐式转换）
  4. byte、short、char 在参与算术运算时会先自动提升为 int 再计算，运算结果也是 int，因此 byte + byte 的结果不能直接赋给 byte 变量（需强转）

隐式转换

自动转换，无需手动转换

强制转换

格式：(目标数据类型) 数据，例如 int a = (int) 10.0;。当源数据的值超出目标类型的取值范围时，会发生精度丢失或溢出，得到的结果不再是原来的数值。

字符串相加

当有字符串参与了加法的执行，那么就会变成拼接而不是相加，如："123" + 123 = "123123"

字符相加

char 参与运算时也会先转换为 int，转换依据是字符在编码表中的编号（Unicode 兼容 ASCII）。因此字符参与运算本质上是拿编号在算：'a' + 'b' 等价于 97 + 98，结果是 int 类型的 195。

短路逻辑运算符

什么是短路逻辑运算符

短路逻辑运算符（&&、||）的计算结果与普通逻辑运算符（&、|）完全一致，差别在于”短路”行为：当左侧表达式已经能够决定整个式子的结果时，右侧表达式就不会再执行。

例如计算 a > 10 && a++ < 11：只要左侧 a > 10 为 false，无论右侧是什么结果都为 false，因此右侧不会执行（a++ 不会生效），既提升了执行效率，也能避免右侧可能出现的除零、空指针等问题。

短路逻辑运算符分类

符号 作用 说明
&& 短路与 并且，两边都为 true，结果为 true
|| 短路或 或者，两边都为 false，结果为 false

instanceof 运算符

instanceof 用于判断一个对象是否是某个类（或其子类、实现类）的实例：是则返回 true，否则返回 false。

格式：对象 instanceof 类型，例如 str instanceof String。

多学一招-原码、反码、补码

什么是原码、反码、补码

  • 原码：十进制整数在计算机中的二进制表示形式，最左侧（最高位）是符号位，0 表示正数、1 表示负数，其余位表示数值本身
  • 反码：正数的反码与原码相同；负数的反码是将原码除符号位外的各位全部取反（0 ↔ 1）
  • 补码：正数的补码与原码相同；负数的补码是在其反码基础上再加 1

举例

原码

计算机底层存储数据用的就是二进制，把”符号位 + 二进制数值”直接拼在一起来表示整数，这种形式就叫原码。例如上述 8 位示例中，+10 的原码就是 0000 1010。

反码

直接用原码参与运算时，正数没有问题，但负数会算错（符号位也参与了运算），于是需要引入反码来改进负数的运算。

解释

补码

反码解决了符号位参与运算导致的错误，但跨过 0 的计算（如正负数相加）结果总会少 1，仍不完美，于是进一步引入补码。

解释

总结

  • 数据在计算机中一律以补码形式存储与运算，得到的结果同样是补码
  • 以 8 位为例，补码能表示的范围是 -128 ~ 127，比原码/反码多出最左边的 -128（即补码 1000 0000），因此该补码没有对应的原码与反码
