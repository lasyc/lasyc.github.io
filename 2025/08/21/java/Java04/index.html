流程控制语句-顺序结构

顺序结构是程序默认的执行方式：代码按照书写的先后顺序，从上到下逐行依次执行。只有遇到分支、循环等语句（或调用方法）时，执行流程才会发生改变。

注意事项

  1. switch 的判断值可以是 byte、short、int、char 及其包装类（Byte、Short、Integer、Character），也可以是 String 和枚举（enum）；不能是 long、float、double 或其它引用类型
  2. default 可以省略，通常写在所有 case 之后；当 default 位于末尾时，其后的 break 也可以省略（后面已经没有 case）
  3. 传统写法中，每个 case 一般都要用 break 结束，否则会发生”穿透”：执行完当前 case 后继续向下执行后续 case 的代码，直到遇到 break 或 switch 结束。穿透多数情况下是 bug，但也可以故意利用它实现”多个值共享同一段代码”（见下方”练习-休息日”）
  4. JDK 14 起正式支持 switch 箭头语法与 switch 表达式（JDK 12、13 中属于预览特性）：case 值 -> 代码 自带 break 效果，无需再写 break，且整个 switch 可以作为一个表达式返回结果

流程控制语句-循环结构

什么是循环

循环就是将指定代码重复执行，直到满足指定条件或者不满足条件时结束

for 循环

for 循环的执行流程：

  1. 先执行一次”初始化语句”（如 int i = 0;）
  2. 判断”循环条件”，为 false 则结束整个循环
  3. 条件为 true 时执行”循环体”
  4. 执行”循环后处理”（如 i++）
  5. 回到第 2 步继续判断，直到条件为 false 才结束

执行流程：先判断条件 → 为 true 执行一次循环体 → 再次判断……直到条件为 false 结束。若一开始条件就不成立，循环体一次也不会执行。

for 与 while 循环的区别

  • for 循环：循环次数相对明确（如输出 1~100、遍历数组）时优先使用。初始化、条件判断、步进都集中在 for 的小括号中，结构一目了然
  • while 循环：事先不清楚要循环几次、只明确结束条件时使用（例如下面折纸问题：不知道要对折几次，只知道厚度要超过珠峰高度）
  • 两者可以互相改写，并没有绝对的使用界限，选择的准则永远是：可读性更好、更不容易出错

do while 循环

注意事项

do...while 与 while 的区别在于判断时机：while 先判断条件再执行循环体（可能一次都不执行）；do...while 先执行一次循环体，再判断条件，因此它至少会执行一次循环体。日常开发中 for 和 while 使用得更多，do...while 了解即可。
