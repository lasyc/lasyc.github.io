无限循环和跳转控制语句

无限循环

无限循环（也称死循环）指循环条件永远成立（或没有条件）而无法自行结束的循环。无限循环本身不是错误，很多场景（如猜数字游戏、消息监听）都会刻意使用它，再借助 break 在合适的时机跳出。

跳转控制语句

在循环中，可以使用跳转控制语句来控制循环的执行：

  • continue：跳过当前循环的剩余部分，直接进入下一次循环
  • break：结束当前循环，跳出整个循环结构

这两个关键字都非常常用，尤其在筛选条件、查找目标值、结束循环等场景中。
