数组的概述和静态初始化

什么是数组

数组是 Java 中最常用的数据结构，可以存储多个相同类型的数据。通常情况下，数组中的元素类型必须一致；如果需要存储不同类型的数据，则需要使用其他数据结构或对象封装。

数组的定义

  1. 格式一：数据类型[] 数组名（推荐写法，把类型与变量名分开，语义更清晰）
  2. 格式二：数据类型 数组名[]（C/C++ 风格，为了兼容才保留，日常不推荐）

静态初始化

在定义数组时，就为数组赋值。静态初始化时，数组的长度即为元素的个数，并且一旦确定，长度就不能再改变。

数组的地址值

数组属于引用数据类型，数组变量中保存的并不是元素本身，而是数组对象在堆内存中的地址。直接打印数组变量时，得到的是类似 [I@6acbcfc0 的内容——严格来说，@ 后面是数组对象哈希码（hashCode）的十六进制形式，可以把它理解为对象的”内存标识”，不同对象、不同运行环境下通常不同。

静态初始化 vs 动态初始化

  • 已知元素的具体值 → 用静态初始化，如 int[] arr = {1, 2, 3};
  • 暂时不知道元素值、只确定需要的长度 → 用动态初始化，如 int[] arr = new int[3];，元素先取默认值，之后再逐个赋值

常见问题

  1. 数组索引越界（ArrayIndexOutOfBoundsException）：下标小于 0 或大于等于数组长度时报错，如长度 5 的数组访问 arr[5]
  2. 空指针异常（NullPointerException）：对值为 null 的数组变量取长度或访问元素时报错，比如 int[] arr = null; 后执行 arr.length

Java 内存区域详解

Java 程序运行时，内存主要分为以下几个区域，每个区域有不同的作用：

区域名称 作用说明
栈（Stack） 存放方法的局部变量、方法调用信息、返回地址等每个线程独享，生命周期与线程一致
堆（Heap） 存放所有对象实例和数组，由垃圾回收器管理所有线程共享，生命周期与 JVM 一致
方法区（Method Area） 存放类的结构信息（类元数据）、静态变量、常量池等所有线程共享
本地方法栈（Native Method Stack） 为本地方法服务，存放本地方法调用信息每个线程独享
程序计数器（Program Counter Register） 记录当前线程执行的字节码行号指示器每个线程独享

说明

  • 栈：每次方法调用都会在栈中分配一块空间，方法结束后自动释放
  • 堆：所有通过 new 创建的对象和数组都存放在堆中，垃圾回收器负责回收无用对象
  • 方法区：用于存储已被虚拟机加载的类信息、常量、静态变量等数据
  • 本地方法栈：支持 Java 调用本地（如 C/C++）方法
  • 程序计数器：帮助线程切换和恢复执行位置

这些区域共同协作，保证 Java 程序的高效运行和内存管理。初学阶段先重点理解栈与堆即可：局部变量在栈中，new 出来的对象和数组在堆中，方法区等概念学到类加载、静态变量时还会再遇到。

数组的内存图

因为数组是引用数据类型，数组变量中保存的并不是元素值本身，而是数组对象在堆中的地址；真正的元素值存放在堆内存中，通过 数组名[下标] 访问。

当把一个数组变量赋值给另一个数组变量时（例如 arr2 = arr1），赋给对方的只是堆中的地址，并不会复制元素。此时两个变量指向堆中同一个数组对象、共享同一份数据：修改其中一方访问到的元素，另一方再访问时看到的也是修改后的值。
