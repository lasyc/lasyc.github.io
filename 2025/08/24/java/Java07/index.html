什么是方法

方法是指一组执行特定任务的代码块，可以被重复调用。它通常包含 方法名、参数列表 和 返回值类型。通过定义方法，可以提高代码的复用性和可维护性。方法是程序中最小的执行单元。

参数

在定义方法时，需要外部提供一些数据，才能完成程序的运行，这些数据称为方法的 参数（形参）。调用者在调用方法时，需要提供 参数（实参）。

如果参数的类型是基本数据类型，那么就是将实参的值赋给形参；当形参的值发生改变时，实参不受影响。

如果参数的类型是引用数据类型，那么传给形参的是实参保存的地址值。由于形参与实参指向堆中同一个对象，在方法内通过形参修改对象的内容时，实参也能看到变化；但如果在方法内让形参重新指向一个新对象，实参的指向并不会改变。

更严谨的说法是：Java 中只有值传递。基本类型传的是”值本身”的拷贝，引用类型传的是”地址值”的拷贝——下文”方法的值传递”一节会详细说明。

方法的小结

  1. 方法的执行需要调用，调用方法时需要使用方法名，并给出参数值；参数的类型和个数必须与方法定义一致。
  2. 方法可以嵌套调用，但不能嵌套定义。
  3. 即使方法的返回值类型是 void，仍可以使用 return 语句结束方法执行；不过 return 后面不能跟任何内容。

什么是方法重载

方法重载（Overload）是指同一个类中，方法名相同，但 参数列表不同 的多个方法。参数列表不同包括：个数不同、类型不同、顺序不同。

方法的基本内存原理

方法调用在内存中的过程可以用”栈帧”来理解：

  1. 每次调用方法，都会在栈中为它分配一块独立空间，这块空间称为栈帧（Stack Frame）
  2. 栈帧中保存该方法的参数、局部变量、返回地址等信息
  3. 方法执行完毕返回时，对应的栈帧被销毁，其中的局部变量随之释放
  4. 方法嵌套调用时（A 调用 B，B 调用 C），栈帧按调用顺序依次”压栈”创建；方法返回时，再按相反的顺序依次销毁

因此递归或嵌套过深时，栈中积累的栈帧过多，会抛出 StackOverflowError（栈溢出）。

基本数据类型和引用数据类型

分类

  • 基本数据类型（共 8 种）：byte、short、int、long、float、double、char、boolean
  • 引用数据类型：除基本类型以外的所有类型，如类（String、自定义类等）、数组、接口。一般通过 new 创建对象后把地址赋给变量（"abc" 这种字符串字面量是特殊写法，本质也属于引用类型）

区别

  • 基本数据类型：变量中直接存储数据本身
  • 引用数据类型：变量中存储的是对象在堆内存中的地址，真正的对象数据存放在堆中

方法的值传递

分类

  • 基本数据类型参数：传递的是实参的值（值的拷贝）。方法内修改形参，不影响实参
  • 引用数据类型参数：传递的是实参保存的地址值（地址的拷贝）。形参与实参指向堆中同一个对象，通过形参修改对象内容会反映到实参

需要澄清一个常见误区：Java 中只有值传递。所谓”引用传递”，本质上传的还是”地址值”这个副本。之所以引用类型的参数表现出”能改到实参”，是因为拷贝过来的地址与实参指向的是同一个堆对象。
