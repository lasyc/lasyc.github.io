买飞机票

下面这道题是典型的分支判断 + 方法封装练习。重点要掌握：

  • 根据月份判断淡旺季
  • 根据舱位类型计算不同折扣
  • 将计算逻辑封装成独立方法

提示：本练习需要 import java.util.Scanner;，下面几个键盘录入的练习同理。

找质数

需求：找出 101~200 之间所有的质数并输出，同时统计一共有多少个。

验证码

需求：生成一个 5 位验证码——前 4 位是随机英文字母（大小写混合），最后 1 位是随机数字。

提示：需要 import java.util.Random;。字符 ‘A’ 的 ASCII 码是 65，’a’ 的 ASCII 码是 97。

数组复制

需求：定义一个方法，把 {1, 2, 3, 4, 5} 的元素逐一复制到新数组并返回（复制的是元素值，而不是地址）。

打分

需求：6 位评委打分，去掉一个最高分、去掉一个最低分后，对剩余 4 个分数求平均，作为选手的最终得分（即比赛中常见的”去掉最高分最低分”规则）。

提示：需要 import java.util.Scanner;

加密和解密

需求：某系统的加密规则为——把原数字的每一位：先加 5，再对 10 取余，得到新的一位数字；最后把所有数字倒序排列，组成密文。请实现加密方法 encrypt 和解密方法 decrypt，并验证解密结果能还原出原文。

示例：1983 加密后为 8346，解密后应还原为 1983。

抢红包

需求：有 5 个红包，金额分别为 10、20、30、40、50 元，模拟随机分配，使每个人抢到的金额不重复、不遗漏。

提示：需要 import java.util.Random;

双色球

需求：模拟双色球开奖号码的生成与比对。为便于练习，这里把规则简化为：从 1~33 中随机生成 7 个互不相同的号码作为中奖号码；用户输入 7 个号码，统计与中奖号码相同的个数，相同的越多、奖项越高（真实双色球是 6 个红球 + 1 个蓝球、规则更复杂，这里不展开）。

提示：需要 import java.util.Random;、import java.util.Scanner;、import java.util.Arrays;

二维数组

什么是二维数组

  • 当一个数组中存储的元素是一个数组时，这个数组就是一个二维数组

练习-求和

需求：某公司全年四个季度（每个季度 3 个月）的营业额存入二维数组，分别统计每个季度的营业额总和，再累加出全年的总营业额。
