面向对象介绍

面向对象编程（Object-Oriented Programming，简称 OOP）是一种编程范式，它使用“对象”来设计应用程序和计算机程序。它利用了抽象、封装、继承和多态这些概念。

类和对象

什么是类和对象

  1. 类：类是创建对象的模板，类中定义了对象的 属性 和 方法。
  2. 对象：通过 类 创建的实例，对象是类的实例化结果。

类的定义

使用 class 关键字定义类，例如：class Person 创建了一个名为 Person 的类。一个类通常由五部分组成：成员变量、成员方法、构造方法、代码块 和 内部类。

注意事项

  1. 类名建议首字母大写，并使用大驼峰命名法（如 Student、Person）
  2. 被 public 修饰的类（主类）必须与文件名一致；一个文件中可以定义多个类，但最多只能有一个 public 类

创建对象

在定义好类之后，就可以通过 new 关键字创建对象，例如：Phone phone = new Phone();。之后，可以通过 phone.属性 或 phone.方法() 来访问对象中的属性和方法。

封装

什么是封装

封装（Encapsulation）是 Java 类的内部机制，它把数据（属性）和行为（方法）封装在一起，并隐藏了实现细节。

封装的好处

在上面的例子中，我们在创建对象后，可以直接通过 对象.属性名 的方式访问属性，例如：student1.age = 18;，但是这样会产生一个问题：没有对数据进行校验，任何值都可以被赋给 age 属性，这样非常不安全。封装的思想就是：将属性通过 private 修饰符封装起来，不允许外部直接访问，而是通过 get、set 方法来访问属性。

private

private 与 public 一样，都是 访问权限修饰符，可以用来修饰 属性 和 方法。被 private 修饰的属性或方法，只能在当前类中访问，外部类无法直接访问。

就近原则和 this 关键字

就近原则

类中的变量称为 成员变量，方法中的变量称为 局部变量。当成员变量和局部变量重名时，优先访问局部变量；若想访问成员变量，可以使用 this 关键字。

this 关键字

this 关键字可以访问当前对象的成员变量和成员方法。当成员变量和局部变量重名时，可以使用 this 来访问成员变量。

构造方法

什么是构造方法

在创建对象时（执行 new），会调用该类的构造方法。借助构造方法，可以在创建对象的同时给属性赋初值。如果类中没有编写任何构造方法，系统会默认提供一个无参构造方法（方法体为空）。

注意事项

  1. 构造方法名称必须与类名相同
  2. 构造方法没有返回值类型和返回值
  3. 只要手动编写了任意一个构造方法，系统就不再自动提供无参构造。因此，为了让 new 类名() 也能创建对象，一般会同时提供无参构造和带参构造（标准 JavaBean 也要求二者齐全）

标准 JavaBean 类

JavaBean 类是一种约定俗成的 Java 类规范，主要包含以下几点：

  1. 属性（成员变量）使用 private 修饰，外界不能直接访问
  2. 为每个属性提供对应的 getter/setter 方法（命名如 getName()、setName(...)），用来读写属性
  3. 提供无参构造方法；一般也提供带参构造方法，方便创建对象时一次性完成赋值

完整意义上的 JavaBean 还需要实现 Serializable 接口（用于对象序列化），入门阶段先掌握以上三点即可。

对象内存图

步骤

  1. 加载类：JVM 首先会检查类是否已加载，如果没有，则加载类的字节码到内存，并进行类的初始化
  2. 分配内存：为新对象分配堆内存空间，保证对象的属性有存储位置
  3. 初始化属性：将成员变量初始化为默认值（如 int 为 0，引用类型为 null）
  4. 执行构造方法：调用构造方法，对对象进行进一步初始化（如设置属性值）
  5. 返回对象引用：构造完成后，将对象的引用返回给变量

对象赋值

对象是引用数据类型，所以 s2 = s1 只是把 s1 保存的引用（地址）复制给了 s2，并不会复制对象本身。此时两个变量指向堆中同一个对象，其中的属性值是共享的：通过任何一个变量修改属性，另一个变量再访问时看到的都是修改后的值。

基本类型和引用数据类型（从内存角度看）

需要区分”变量本身”和”数据/对象本身”两个概念：

  • 基本数据类型的局部变量：变量的值直接存放在栈中
  • 引用数据类型的对象：通过 new 创建的对象存放在堆中，栈中的变量保存的是该对象的地址（引用）
  • 如果基本类型变量是对象的成员变量，它会随着对象一起存放在堆中（而不是栈中）

一句话记忆：栈中存引用，堆中存对象。基本类型的”值”要么在栈中（局部变量），要么随对象在堆中（成员变量）。

this 内存

this 指向”当前正在执行方法的那个对象”：哪个对象调用了方法，方法内部的 this 就指向哪个对象。因此通过 this.属性 总能访问到当前对象自己的成员变量，从而解决成员变量与局部变量重名时的取值问题。

成员变量和局部变量

区别 成员变量 局部变量
声明位置 类中 方法中
初始值 默认值 未赋值
存储位置 堆 栈
生命周期 随对象创建而存在，对象被回收时消亡 随方法调用而创建，方法结束即销毁
作用域 类内 方法内

补充说明：存储位置一栏针对的是常见情况——局部变量都存放在栈中；成员变量则随对象存放在堆中（即使是 int 这类基本类型的成员变量也随对象在堆）。
