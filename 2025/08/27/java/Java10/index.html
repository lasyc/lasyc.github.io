需求：定义商品类 Good（编号、名称、价格、库存），创建 3 个商品对象存入对象数组，再遍历数组把每个商品的属性打印出来。

提示：需要 import java.util.Scanner;

数组练习 5

需求：用对象数组模拟一个简单的”学生管理系统”：先初始化 5 个学生，再支持①添加学生（学号不能重复，数组满了自动扩容）②按学号删除学生，每次操作后把当前全部学生打印出来。
