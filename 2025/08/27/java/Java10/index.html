文字版格斗游戏

这类题目是面向对象综合练习的典型案例，重点考察：

  • 类的设计
  • 对象属性和方法的封装
  • 参数传递和对象引用
  • while 循环与条件判断

数组练习 1

需求：定义商品类 Good（编号、名称、价格、库存），创建 3 个商品对象存入对象数组，再遍历数组把每个商品的属性打印出来。

数组练习 2

需求：定义汽车类 Car（品牌、价格、颜色），键盘录入 3 辆汽车的信息存入数组，再遍历数组打印每辆汽车（Car 重写了 toString，直接打印对象即可）。

提示：需要 import java.util.Scanner;

数组练习 5

需求：用对象数组模拟一个简单的”学生管理系统”：先初始化 5 个学生，再支持①添加学生（学号不能重复，数组满了自动扩容）②按学号删除学生，每次操作后把当前全部学生打印出来。

提示：需要 import java.util.Scanner;。数组一旦创建长度就固定不变，本练习通过”复制到更长的新数组”来模拟动态扩容。
