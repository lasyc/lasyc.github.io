集合的基本使用

为什么要有集合

当我们需要存储多个同一类型的数据时，可以使用数组，但 数组的长度是固定 的，无法动态调整。集合可以根据需要动态扩展，提供了更灵活的数据存储方式。不过相比于数组，集合无法直接存储基本数据类型，通常要用包装类来存储。

ArrayList

ArrayList 是 Java 中最常用的集合类之一，它实现了 List 接口，允许存储重复的元素，并且元素有序（大致按添加顺序排列）。

提示：ArrayList 位于 java.util 包，使用前需要 import java.util.ArrayList;。尖括号 <> 里写的是集合要存储的元素类型，这种写法叫泛型；new 后面 <> 里的类型可以省略（钻石语法）。

练习-遍历

需求：创建一个存有 4 个字符串的集合，遍历取出每个元素，用 StringJoiner 把它们拼接成 [a, b, c, d] 的格式输出。

提示：需要 import java.util.ArrayList; 和 import java.util.StringJoiner;。遍历集合与遍历数组类似，用 size() 取长度、get(i) 按下标取元素。

包装类

前面提到，集合无法直接存储基本数据类型的数据（数组可以，集合不行），因此包装类应运而生。包装类就是基本数据类型对应的引用数据类型形式，例如 byte 的包装类是 Byte。需要存储数字时，集合里放的是对应的包装类对象。
