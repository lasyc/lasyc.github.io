Java static 与继承

发表于2025-09-06|更新于2026-09-12|后端语言基础Java

static 静态变量

static 是 静态修饰符，用于修饰 成员变量 和 成员方法。当一个 成员变量 被 static 修饰后，这个成员变量就被称为 静态成员变量。该类的所有实例化对象都会 共享 这个变量，并且可以通过类名直接访问，例如：Student.teacherName。

static 静态方法和工具类

静态方法

同理，被 static 修饰的方法称为静态方法，使用类名即可直接调用，无需先实例化对象，如：Math.abs()，多用于工具类中

工具类

工具类是指一些静态方法的集合，通常不需要实例化对象即可使用。常见的工具类有：java.lang.Math、java.util.Collections 等。

static 的注意事项

  1. 在静态方法内，只能访问静态变量和静态方法
  2. 在非静态方法内，既可以访问静态变量和静态方法，也可以访问非静态变量和非静态方法
  3. 静态方法中不能使用 this 关键字

继承

什么是继承

继承是面向对象三大特征之一，它描述的是 类与类之间 的关系。简单来说，就是一个类可以继承另一个类的成员变量和成员方法，形成一种典型的 IS-A 关系。

继承的作用

前面已经学过实体类。若多个实体类具有相同的属性和方法，就可以将这些公共内容提取出来，定义在一个公共类中。这个公共类就是 父类；而这些实体类则可以 继承父类，称为 子类。子类不仅可以直接使用父类中定义的属性和方法，还可以继续添加新的属性和方法，或者对父类方法进行 覆盖（重写）。

继承的语法

继承的语法：public class 子类 extends 父类

继承的特点

特点

  1. 一个子类只能继承一个父类，但是一个父类可以有多个子类
  2. 继承支持多级继承，如：A extends B，B extends C，这样子 B 可以获得 C 的属性和方法，A 可以同时获取 B 和 C 的属性和方法
  3. Java 中的所有类都直接或间接继承自 Object 类，Object 类是所有类的根类

子类到底能继承父类的哪些属性和方法？

分类

分类 私有 非私有
构造方法 不能继承 不能继承
成员变量 可以继承（不能直接使用） 可以继承
成员方法 不能继承 可以继承（虚方法表）

解释说明

  1. 因为构造方法要求必须与类名相同，所以子类不能继承父类的构造方法
  2. 父类的成员变量私有属性，子类可以继承，但是不能直接访问，需要通过暴露出来的 set/get 方法进行访问
  3. Java 底层会创建一个虚方法表，从 Object 类开始，以此类推，把类中的非 private、非 static、非 final 的方法都提取到虚方法表中，子类会继承虚方法表，直至继承结束，最终的子类通过虚方法表会继承前边所有类的方法

继承中成员变量和方法的访问特点

成员变量

当子类和父类存在同名成员变量时，访问变量时遵循就近原则，即：局部变量 > 子类成员变量 > 父类成员变量。如果想指定访问子类变量，前面已经学过可以使用 this 关键字；若想访问父类变量，则使用 super 关键字。

成员方法

与成员变量同理，在此基础上，若子类的方法和父类的方法重名，这种情况称为方法的重写，主要用于当父类方法不能满足需求时，进行方法重写，子类方法会替换掉父类方法，还需要再添加@Override 注解，表示该方法是重写父类的方法

重写注意事项

  1. 重写方法的名称和形参列表必须和父类方法一致
  2. 访问权限修饰符必须大于等于父类方法（private < default < protected < public）
  3. 返回值类型必须和父类方法一致，或者子类方法返回值类型是父类方法返回值类型的子类

构造方法

子类不能继承父类的构造方法，但在执行子类自己的构造方法时，Java 会在内部自动先调用父类的构造方法，然后再执行子类构造方法中的后续代码。这是因为子类需要使用父类中的数据；如果父类还没有完成初始化，子类就无法正常使用这些内容。当然，也可以通过 super() 显式调用父类构造方法，而且必须写在 第一行。

this 和 super

  1. this 关键字，表示当前对象
  2. super 关键字，表示父类对象
