登录注册

说明：原文此处只写了”略”。登录/注册与前面章节的窗口骨架对应，课程完整版一般还会把注册用户写入本地文件（需要 IO 流）、加图形验证码等。下面给出一个简化可运行的参考实现（只演示主流程），学完 IO 相关章节后可自行改成文件存储。

登录窗口的逻辑：用户在输入框里填写账号、密码，点击”登录”按钮后与”已注册用户”比对，一致就进入游戏主界面，不一致就弹窗提示。

注册窗口的思路与前面”学生管理系统”里的注册校验一致：收集账号、密码、确认密码，校验两次密码一致且满足基本规则（如长度限制）后，把新用户保存起来（这里简化为只打印一行提示，正式版可存进集合或写入文件），再提示注册成功。校验逻辑部分可参考 Java13（学生管理系统）中的 checkUsername、checkPassword 等写法，这里不再重复展开。
