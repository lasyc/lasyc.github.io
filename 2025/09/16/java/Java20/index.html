正则表达式

正则表达式作用

  1. 验证字符串是否符合某种规则
  2. 查找字符串中符合某种规则的内容
  3. 替换字符串中符合某种规则的内容

普通字符

字符 说明
[ABC] 匹配 A、B、C 中的任意一个字符
[^ABC] 匹配不为 A、B、C 的任意字符
[A-Z] 匹配 A-Z 范围内的任意字符
[a-d[m-p]] 匹配 a-d 或 m-p 范围内的任意字符
[a-z&&[def]] 匹配 a-z 和 d、e、f 中的交集，即：d、e、f
[a-z&&[^bc]] 匹配 a-z 范围内，且不为 b、c 的任意字符
[a-z&&[^m-p]] 匹配 a-z 范围内，且不为 m-p 的任意字符

预定义字符

字符 说明
. 匹配除换行符以外的任意单个字符（空格也能匹配）
\d 匹配任意数字，等价于 [0-9]
\D 匹配任意非数字，等价于 [^0-9]
\s 匹配任意空白字符
\S 匹配任意非空白字符
\w 匹配任意字母、数字、下划线
\W 匹配任意非字母、数字、下划线

代码示例

数量词

字符 说明
X? 匹配 0 次或 1 次 X
X* 匹配 0 次或多次 X
X+ 匹配 1 次或多次 X
X{n} 匹配 n 次 X
X{n,} 匹配至少 n 次 X
X{n,m} 匹配至少 n 次，至多 m 次 X

贪婪爬取和非贪婪爬取

  1. 贪婪爬取：尽可能多地匹配字符，直到整个字符串都被匹配完为止
  2. 非贪婪爬取：尽可能少地匹配字符，满足条件后就停止匹配

替换和分割

在字符串方法中，replaceAll 和 split 方法都支持正则表达式

分组

正则表达式中，() 表示一个分组。每个分组都有一个组号，从左往右从 1 开始编号；在正则内部可以用 \n（n 为组号）引用对应分组已匹配到的内容，在正则外部（比如 replaceAll 的替换字符串里）则用 $n 引用。
