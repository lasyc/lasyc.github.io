JDK 7 时间类

先补充几个背景知识：

  1. UTC（协调世界时）：国际标准时间，也就是世界标准时间
  2. 中国标准时间：UTC 时间 + 8 小时
  3. 单位换算：1 s = 1000 ms，1 ms = 1000 μs，1 μs = 1000 ns

本小节的 Date、Calendar 在 java.util 包中，SimpleDateFormat 在 java.text 包中，代码示例里省略了 import。

Date

Date 类用来表示一个特定的瞬间，精确到毫秒。创建 Date 对象时会自动获取当前时间；也可以向构造方法传入时间戳（毫秒值）来指定时间，例如 new Date(0L) 表示时间原点 1970-01-01 08:00:00（东八区）。

Calendar

虽然 Date 类已经提供了不少方法，但要处理”某个时间的前一天/后一天、前一月/后一月”这类需求仍然很繁琐，Calendar 类把这些操作封装成了方法，用起来方便很多。

Calendar 是一个抽象类，不能直接 new，需要通过静态方法 getInstance() 获取它的对象。相比 Date，Calendar 功能更强大：可以按字段（年、月、日、时、分、秒……）分别设置或获取时间，也可以用 add 直接对某个字段做加减。

Duration、Period、ChronoUnit

这三个类都用来计算两个时间点之间的间隔，但侧重点不同：

  • Duration：计算两个”时间”之间的间隔，但只能精确到秒和纳秒，适合算时分秒这种小于一天的间隔；
  • Period：计算两个”日期”之间的间隔，可以按年、月、日统计，适合算年龄；
  • ChronoUnit：时间单位的枚举，可以按年、月、日、时、分、秒、纳秒等任意单位，计算两个时间之间的差值。

包装类

包装类可以理解为”把基本数据类型包装成对象”的类：每个基本数据类型都对应一个包装类。基本类型不是对象，使用上有很多限制——比如变量不能赋 null、不能放进集合（集合只能存对象）、不能参与多态，包装类正是为了解决这些问题而生的。
