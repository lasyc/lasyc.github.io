查找

基本查找

基本查找也称为顺序查找，它是通过遍历整个数组或集合来查找目标元素。时间复杂度为 O(n)，空间复杂度为 O(1)。

二分查找

二分查找是基于有序数组的一种查找方式。它每次从中间位置开始比较，并排除掉一半元素，直到找到目标值。时间复杂度为 O(log n)，空间复杂度为 O(1)。二分查找要求数组必须是 有序 的。

插值查找

插值查找是一种更高效的查找方式，它会根据目标值和数组范围的关系，估算目标元素大致的位置，然后再进行查找。时间复杂度通常为 O(log log n)，空间复杂度为 O(1)。它同样要求数组是 有序 的，并且数据量较大、分布比较均匀时效果才明显；如果数据分布极不均匀，可能比二分查找还慢。

斐波那契查找

斐波那契查找利用斐波那契数列来确定元素可能出现的位置，再进行比较和缩小范围。时间复杂度为 O(log n)，空间复杂度为 O(1)。它也要求数组是 有序 的。

说明：标准的斐波那契查找还需要把原数组”填充”到斐波那契数列对应的长度（多出的位置用最大值补上），代码会复杂不少。这里给出的是教学简化版，只演示核心思路，没有做数组填充，个别边界情况可能照顾不到，理解算法思想即可。

分块查找

分块查找是把数组分成多个小块，并在每块中保存一个最大值。查找时，先确定目标元素可能在哪一块，再在该块中进行顺序查找。时间复杂度为 O(√n)，空间复杂度为 O(1)。

排序

冒泡排序

冒泡排序通过两两比较相邻元素，把最大（或最小）的元素一步步”冒”到数组末尾（或开头），然后重复上述过程，直到数组有序。时间复杂度为 O(n^2)，空间复杂度为 O(1)。

选择排序

选择排序通过每轮找出数组中的最小（或最大）元素，把它放到数组的起始位置，然后重复上述过程，直到数组有序。时间复杂度为 O(n^2)，空间复杂度为 O(1)。

插入排序

插入排序把数组划分为”已排序”和”未排序”两部分，每一轮把未排序部分的第一个元素插入到已排序部分的正确位置，直到数组有序。时间复杂度为 O(n^2)，空间复杂度为 O(1)。

递归

递归通过把一个大问题分解成更小的同类子问题，直到子问题可以直接解决，再逐层返回、组合子问题的解，从而得到原问题的解。递归方法要特别注意”递归出口”，否则会无限调用、栈溢出。

快速排序

快速排序先选定一个基准值（pivot），通过一趟交换把数组分成两部分：左边都小于等于基准，右边都大于基准；然后对左右两个子数组递归地重复这个过程，最终整体有序。平均时间复杂度为 O(n log n)，空间复杂度为 O(log n)（递归栈）。

Lambda

Lambda 表达式是 Java 8 引入的新特性，用来简洁地表示函数式接口的实现。函数式接口指只包含一个抽象方法的接口，可以用 @FunctionalInterface 注解来标记、声明它是一个函数式接口（加了这个注解后，若接口里有多个抽象方法，编译会直接报错提醒）。

注意事项

  1. Lambda 只能用来实现接口（准确说是函数式接口），不能用来继承类
  2. 函数式接口中只能有一个抽象方法
  3. Lambda 语法格式：(参数列表) -> {方法体}
  4. 参数类型可以省略，编译器会根据上下文自动推导
  5. 如果方法参数列表只有一个参数，可以省略小括号
  6. 如果方法体只有一条 return 语句，可以省略大括号和 return 关键字

兔子问题（斐波那契数列）

经典斐波那契问题：有一对兔子，从出生后第 3 个月开始每个月生一对兔子，假设兔子永远不会死，问第 n 个月一共有多少对兔子？数量序列为 1、1、2、3、5、8……从第 3 个月起，当月数量等于前两个月数量之和。
注意：以”第 1 个月 1 对”为起点，第 12 个月对应序列第 12 项，即 144 对。

猴子吃桃（倒推）

有一堆桃子，猴子每天吃掉当天桃子数量的一半、再多加一个，以此类推，到第 10 天早上只剩 1 个桃子，问最初（第 1 天开始）有多少个桃子？
思路：从第 10 天往前倒推。”吃掉一半再多一个”后剩下的桃子 = 当天数量 ÷ 2 − 1，反过来，第 n 天开始的数量 =（第 n+1 天开始的数量 + 1）× 2。
注意：这里方法名也写成了 fibonacci，但它和上面的兔子问题、下面的爬楼梯没有任何关系。这几个练习相互独立，若要放进同一个类，记得给方法改名（并注意 main 也会重名）。

爬楼梯（每次 1 或 2 阶）

思路：到第 n 阶的方法数 = 到第 n−1 阶的方法数（最后一步爬 1 阶）+ 到第 n−2 阶的方法数（最后一步爬 2 阶）。到第 1 阶有 1 种、到第 2 阶有 2 种。

爬楼梯（每次 1、2 或 3 阶）

思路同上，只是最后一步多了一种可能：到第 n 阶的方法数 = 到第 n−1、n−2、n−3 阶方法数之和。注意这里到第 3 阶一共有 4 种方法（1+1+1、1+2、2+1、3），所以基准值是 1、2、4，而不是 1、2、3——原示例的基准写错会导致第 20 阶算成 101902，修正后才是 121415。
