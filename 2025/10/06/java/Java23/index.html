Java 集合体系与 List

发表于2025-10-06|更新于2026-09-12|后端语言基础Java

集合的体系结构

集合大致分为两大类：Collection 和 Map。其中，Collection 是单列集合，每个位置只能保存一个值；而 Map 是双列集合，每个位置保存的是一个键值对（key 和 value 两个值）。

Collection

Collection 接口是所有单列集合的根接口，下面通过 List、Set、Queue 三个子体系来分类。

  • List：有序且可重复的集合，常用实现类有 ArrayList 和 LinkedList
  • Set：无序且不可重复的集合，常用实现类有 HashSet 和 TreeSet
  • Queue：用于存储待处理元素的集合，常用实现类有 LinkedList 和 PriorityQueue

常用方法

方法名 描述
add 添加元素
clear 清空集合
remove 删除元素
contains 判断是否包含某个元素
isEmpty 判断集合是否为空
size 返回集合中元素的个数

遍历

对于 Collection 集合，有三种遍历方式：分别是迭代器、增强 for 和 Lambda。

迭代器

迭代器是集合的一种遍历方式，它提供了一种顺序访问集合元素的方式。迭代器提供了 hasNext() 和 next() 方法，用于判断集合中是否有下一个元素，并返回下一个元素。迭代器还提供了 remove() 方法，用于删除当前元素。

在迭代过程中，不能直接修改集合中的元素，只能通过迭代器进行修改。因为迭代器在初始化时会记录集合当前的修改次数，每次调用 next() 方法时，都会检查集合的修改次数是否与迭代器记录的修改次数相同。如果集合被修改，集合中的修改次数会发生变化，与迭代器记录的次数不同，则会抛出 ConcurrentModificationException 异常。

方法名 描述
hasNext() 判断是否有下一个元素
next() 获取下一个元素
remove() 删除当前元素
  1. 迭代器只能使用一次，每次使用都需要重新获取迭代器对象
  2. 迭代器在遍历过程中不能通过集合的 remove 方法删除元素，必须通过迭代器的 remove 方法删除元素
  3. 迭代器是单向遍历的，只能向前遍历，不能向后遍历

增强 for

增强 for 其实是语法糖，底层也是使用迭代器实现的。它不仅可以遍历 Collection 集合，还可以遍历数组。

  1. 使用增强 for 遍历集合时，如果修改了 item 的值，集合中元素不会改变，因为 item 是集合中元素的一个副本

Lambda

基于 Collection 接口的 forEach 方法，可以使用 Lambda 表达式遍历集合。forEach 底层使用的是迭代器实现的，但 ArrayList 集合除外——ArrayList 的 forEach 方法底层使用的是索引 for 实现的。

数据结构

数据结构是计算机科学中重要的概念，它描述了数据如何存储和操作。Java 中常用的数据结构有数组、链表、栈、队列、树、图等。

栈

栈是一种 Last In First Out（LIFO）的数据结构，它遵循后进先出原则：后入栈的元素，先出栈。

队列

队列是一种 First In First Out（FIFO）的数据结构，它遵循先进先出原则：先入队列的元素，先出队列。

数组

数组是一种有序的集合，它按照索引顺序存储元素。数组的元素在内存中是连续的，因此可以快速访问任意位置的元素（查询快）；但是对于插入和删除元素，数组效率较低（增删慢）。

链表

链表是一种通过指针把元素一个个链接起来的数据结构。链表在内存中不连续，因此不能通过索引直接访问元素；但链表可以快速插入和删除元素，而查询效率较低（查询慢，增删快）。

树

树是一种 hierarchical（层次）的数据结构，它通过父子节点的关系来将节点进行连接，组成一个树形结构。

  1. 一个节点只有一个父节点，而一个父节点可以有多个子节点
  2. 子节点的个数称为度
  3. 最顶层的节点称为根节点，根节点没有父节点
  4. 度为 0 的节点称为叶子节点

二叉树

二叉树是一种树形结构，它的每个节点最多有两个子节点。

二叉搜索树

二叉搜索树是一种二叉树，它满足以下条件：若每个节点的左子树中所有节点都小于本身，且右子树中所有节点都大于本身，则该树为二叉搜索树。

二叉树的遍历方式

  1. 前序遍历：根节点 -> 左子树 -> 右子树
  2. 中序遍历：左子树 -> 根节点 -> 右子树
  3. 后序遍历：左子树 -> 右子树 -> 根节点
  4. 层序遍历：从根节点开始，依次访问每一层的节点

二叉搜索树的弊端

因为二叉搜索树要求节点的左子树都小于根节点、右子树都大于根节点，所以在添加元素时，如果添加的元素一个比一个大，就会全部被添加到右子树中，这样树就变成了”一条直线”，退化成类似链表的结构，查询效率大大降低。例如依次添加 ① ② ③ ④ ⑤ ⑥ ⑦ 时，每个新元素都会成为前一个元素的右子节点，最终形成如下结构：

平衡二叉树

平衡二叉树是一种二叉树，它的每个节点的左右子树的高度差不超过 1。平衡二叉树是通过旋转机制来达到平衡的，旋转又分为左旋和右旋两种。当添加元素时，若某个节点的左右子树高度差超过 1，则需要进行旋转，通过旋转让树始终处于平衡状态。

左旋

左旋把失衡节点”往下压”：让失衡节点的右子节点变成新的父节点，失衡节点自己变成新父节点的左子节点；若右子节点原本带有左子节点，则把这个左子节点”过继”给失衡节点，作为失衡节点新的右子节点。示例：

旋转的应用场景

  1. LL：当添加的元素添加到左子树的左子节点时，则需要将整体进行一次右旋
  2. LR：当添加的元素添加到左子树的右子节点时，则需要先将左子树进行一次左旋，变成LL，再将整体进行一次右旋
  3. RR：当添加的元素添加到右子树的右子节点时，则需要将整体进行一次左旋
  4. RL：当添加的元素添加到右子树的左子节点时，则需要先将右子树进行一次右旋，变成RR，再将整体进行一次左旋

平衡二叉树的弊端

平衡二叉树的查询效率比二叉搜索树高，但是每次添加元素时，都可能需要进行旋转，频繁旋转的效率较低。由此诞生了红黑树。

红黑树

红黑树是一种自平衡的二叉搜索树，它的每个节点都有颜色，颜色分为红色和黑色。红黑树并不是高度平衡的，但它是自平衡的——它并不严格要求左右子树高度差不超过 1，而是通过红黑规则让树大体保持平衡，从而减少旋转次数。

红黑规则

红黑树依靠以下规则来维持平衡（注：规则 3 和规则 4 说的是同一件事——不允许出现两个连续的红色节点）：

  1. 每个节点都是黑色或者红色
  2. 根节点是黑色
  3. 如果一个节点是红色，则它的父节点和两个子节点都是黑色（红色节点的父节点不能是红色，否则就出现了连续的红色节点）
  4. 不存在连续两个节点都是红色
  5. 所有叶子节点（NIL 节点）都是黑色
  6. 从任意节点到其叶子节点的所有路径上，都包含相同数量的黑色节点（即黑高相同）

红黑树插入节点的颜色处理规则

注意：以下规则仅为插入操作中部分情形的处理方式，完整实现还需考虑更多细节及连锁反应

节点状态 颜色处理说明
默认 新插入的节点默认为红色，目的是尽可能不破坏原有的黑高路径
根节点 若新节点成为根节点，则必须将其颜色设置为黑色
黑色父节点 插入红色子节点不会违反任何红黑树性质，因此不需要进行任何调整
红色父节点 + 红色叔节点 - 父节点 → 黑色
- 叔节点 → 黑色
- 祖父节点 → 红色（如果祖父是根节点，则再变回黑色）
- 然后递归向上检查祖父节点
红色父节点 + 黑色叔节点 + 当前节点在右子树 此时需要进行左旋操作，使结构转换为 LL 型，然后再进一步处理
红色父节点 + 黑色叔节点 + 当前节点在左子树 - 父节点 → 黑色
- 祖父节点 → 红色
- 对祖父节点进行右旋操作完成结构调整

List

List 集合的特点是：有序、可重复、有索引。常用的实现类有：ArrayList、LinkedList 和 Vector。

常用方法

ArrayList

ArrayList 是基于数组实现的，默认容量为 0，当首次添加元素时，才将数组的容量扩大为 10。后续再次添加元素时，若数组容量不够，会自动扩容，扩容后的大小为原容量的 1.5 倍；但如果扩容后仍不足以容纳所有元素，则会直接扩容到实际需要的大小。

LinkedList

LinkedList 是基于链表实现的，它不支持索引访问，但它是双向链表的实现：每个节点都有前驱和后继，通过前后指针把节点串起来（注：LinkedList 并不是循环链表，循环链表只是链表的一种扩展形式）。在添加元素时，会创建新的节点，并将新节点链接到链表的末尾；在删除元素时，会删除指定节点，并将指定节点的前驱和后继节点直接链接起来。

独有方法

方法 描述
addFirst(E e) 在链表开头添加元素
addLast(E e) 在链表末尾添加元素
removeFirst() 删除链表开头的元素
removeLast() 删除链表末尾的元素
getFirst() 获取链表开头的元素
getLast() 获取链表末尾的元素

Vector

Vector 与 ArrayList 类似，也是基于数组实现的，但它是线程安全的。Vector 的扩容策略是每次扩容为原容量的 2 倍，而 ArrayList 是 1.5 倍。由于 Vector 的方法大多带有同步锁（synchronized），在单线程环境下性能不如 ArrayList，所以现在基本被 ArrayList 取代。
