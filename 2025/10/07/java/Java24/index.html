Java 泛型与 Set

发表于2025-10-07|更新于2026-09-12|后端语言基础Java
|总字数:2.9k|阅读时长:11分钟|浏览量:

泛型

泛型（Generics）是一种类型参数化的写法，它可以用来创建类型安全的、可复用的代码：使用泛型后，很多类型错误可以在编译阶段就暴露出来，而不是等到运行时才报错。

补充：Java 中的泛型其实是伪泛型——泛型是编译时的特性，编译后泛型信息会被擦除（类型擦除），所以运行时集合中并不真正保存泛型类型。可以通过反射机制在运行时向集合中添加泛型以外的元素，不过正常开发中不建议这么做。

泛型类

泛型类的定义格式为：class 类名<T>，其中 T 表示类型参数

泛型方法

泛型方法的定义格式为：public <T> void method(T t)，其中 T 表示类型参数

泛型接口

泛型接口的定义格式为：interface 接口名<T>，其中 T 表示类型参数。当其他接口继承该接口、或者其他类实现该接口时，可以指定具体的类型参数，也可以继续使用泛型。

泛型的继承和通配符

泛型本身不具备继承关系（List<Zi> 并不是 List<Fu> 的子类型），但可以通过通配符来放宽泛型的类型限制。

通配符

通配符是一种类型参数，它可以表示任意类型

  • ? 表示任意类型（无限制）
  • <? extends T> 表示 T 及其子类（上限）
  • <? super T> 表示 T 及其父类（下限）

Set

Set 集合的特点是：无序、不可重复、无索引。常用的实现类有 HashSet、TreeSet 和 LinkedHashSet。Set 集合继承自 Collection 接口，所以也继承了 Collection 的所有方法。

HashSet

HashSet 是基于哈希表实现的，查询速度快，适合存储大量数据。它的特点是无序、不重复、无索引。

哈希表：JDK 8 以前，是数组 + 链表的实现方式；JDK 8 之后，是数组 + 链表 + 红黑树的实现方式。在添加数据时，会先计算出该数据的哈希值，再根据哈希值找到数组中对应的位置；如果该位置已经存在数据，则将新数据追加到该位置的链表上。

哈希值：哈希值是通过 hashCode() 方法计算得到的，该方法在 Object 类中定义，所以所有类都继承了该方法。该方法默认使用对象地址计算哈希值，所以对象地址相同，哈希值也相同。但是一般情况下都会重写 hashCode() 方法，利用对象属性计算哈希值，对象属性相同，哈希值也相同。尽管如此，仍有极小概率出现：地址不同、属性值也不同，但哈希值却相同的情况，我们称之为哈希碰撞。

存储原理

HashSet 存储原理：在对象被创建时，会创建一个默认长度为 16 的数组，默认负载因子为 0.75。当数组中的元素个数达到数组长度的 0.75 倍（即 12 个）时，数组会扩容为原来的2倍。数组的每个位置都可以挂一个链表，哈希值重复的元素会存储在同一个位置的链表中。当链表长度超过8，且数组长度超过 64 时，链表会转换为红黑树。

添加元素：在添加元素时，会先通过 hashCode 方法计算出哈希值，然后再通过 (数组长度 - 1) & 哈希值 计算出数组索引，把元素放到对应位置。如果该索引位置已存在元素，再通过 equals 方法判断是否相同：如果相同，则不添加；如果不同，则添加到该位置的链表上。另外，不同版本的 JDK 添加方式不一样：JDK 8 以前使用的是头插法，JDK 8 之后使用的是尾插法。

LinkedHashSet

LinkedHashSet 继承自 HashSet，在其基础上新增了一条链表，用于记录元素的插入顺序，因此具备了有序的特点。

存储原理

存储原理同 HashSet 无异，只不过在添加元素时，会额外通过双向链表记录元素的插入顺序：每个元素都会记录它的前一个元素和下一个元素，通过这条链表就可以按插入顺序遍历。

TreeSet

TreeSet 是基于红黑树实现的，因此它具备有序的特点，但是这个顺序并不是插入顺序，而是默认为升序排列。

添加元素：因为 TreeSet 是有序的，所以在添加元素时，会将该元素与已有元素比较，来确定该元素应该排在哪里。所以在向 TreeSet 中添加自定义类型的元素时，必须声明比较规则。有两种实现方式：1. 自定义类实现 Comparable 接口，并重写 compareTo 方法；2. 在构造 TreeSet 对象时，通过 Comparator 参数指定比较规则。

底层源码

Set 系列的底层实现都是基于 Map 接口的：HashSet 对应 HashMap、TreeSet 对应 TreeMap、LinkedHashSet 对应 LinkedHashMap。

Map

Map 接口是所有双列集合的根接口，它存储的是键值对（key 和 value），每个键只能对应一个值。常用的实现类有 HashMap、TreeMap 和 LinkedHashMap。

  • HashMap：基于哈希表实现，查询速度快，适合存储大量数据
  • TreeMap：基于红黑树实现，支持按键排序，适合需要有序存储的场景
  • LinkedHashMap：基于哈希表和链表实现，保持插入顺序，适合需要有序遍历的场景
