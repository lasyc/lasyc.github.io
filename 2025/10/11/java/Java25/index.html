Java Map 集合与源码解析

发表于2025-10-11|更新于2026-09-12|后端语言基础Java
|总字数:4.5k|阅读时长:19分钟|浏览量:

说明：本文示例会用到 java.util 包下的 Map、HashMap、TreeMap、LinkedHashMap、Collections、List、ArrayList、Set、Random 等类，练习前请按需 import（IDEA 中光标放在类名上按 Alt+Enter 可自动导入）。

双列集合的特点

双列集合是一个将键映射到值的集合，其中保存两个值：键（key）和值（value），合起来称之为键值对。其中键不能重复，值可以重复。

Map

常用方法

方法 描述
put(K key, V value) 将指定的键值对添加到 Map 集合中。如果添加的键已存在，则更新其对应的值
remove(Object key) 根据指定的键，删除对应的键值对
clear() 删除所有键值对
containsKey(Object key) 判断 Map 集合中是否存在指定的键
containsValue(Object value) 判断 Map 集合中是否存在指定的值
isEmpty() 判断 Map 集合是否为空
size() 返回 Map 集合中键值对的数量

HashMap

HashMap 实现了 Map 接口，拥有 Map 接口的所有方法，底层通过哈希表（数组 + 链表 + 红黑树）实现，具有无序、键不重复、值可重复、无索引的特性（这里的无序指的是遍历顺序与添加顺序不一定一致）。

在存入哈希表计算哈希值时，只使用键的 hashCode 方法计算哈希值，然后通过哈希值对数组长度取模得到数组索引。所以如果键是自定义类，则必须重写 hashCode 和 equals 方法，而值则不需要。

学生对象作为 key

创建一个 HashMap，key 为学生对象，value 为学生籍贯，同名同年龄的学生认为是同一个人。

统计景点投票数

某班级共 80 名学生，从 天安门、故宫、天坛、鸟巢、长城 五个景点中投票，使用 HashMap 统计每个景点的票数，并找出票数最多的景点。

需要 import java.util.Random;（用于随机投票）。

LinkedHashMap

LinkedHashMap 继承自 HashMap，它在 HashMap 的基础上额外维护了一条双向链表，用来记录元素的插入顺序。所以它具备有序（遍历顺序与插入顺序一致）、键不重复、无索引的特性。

TreeMap

TreeMap 实现了 Map 接口，底层实现与 TreeSet 一致，都是红黑树。TreeMap 按照 key 的大小进行排序，默认是升序（从小到大），也可以在构造时传入 Comparator 指定排序规则。所以它具备有序、键不重复、无索引的特性。

HashMap 源码解析

HashMap 底层实现原理：数组 + 链表 + 红黑树。

在 HashMap 中，数组 table 用于存放元素，默认长度是 16，负载因子为 0.75。扩容阈值 = 数组长度 × 负载因子 = 16 × 0.75 = 12，当数组中的元素个数达到 12 时，会触发扩容（扩容后数组长度翻倍，阈值也会重新计算）。

在 HashMap 中，每一个键值对都是一个 Node 对象，其中包含了 hash、key、value、next 等属性；当链表转为红黑树时，则会使用 TreeNode 节点对象，其中又包含了 parent、left、right、prev、red 等属性。

空参构造函数：什么都不做，甚至不创建数组，只是把负载因子 loadFactor 设为 0.75（注释里的 all other fields defaulted 意思是：其他字段都使用默认值）。真正的扩容阈值 threshold 要等第一次添加元素、数组初始化时才会被计算出来。

添加键值对：首次调用 put 添加键值对时，才会真正创建数组（懒加载）。

TreeMap 源码解析

TreeMap 是一个红黑树结构，用于存储键值对。其中每一个键值对都是一个 TreeNode 节点对象，该节点对象包含键、值、颜色、左子节点、右子节点、父节点等信息。

构造函数：TreeMap 的默认构造函数创建一个空的 TreeMap 对象，但不会指定比较器，此时就要求键对象必须实现 Comparable 接口（否则添加元素时会抛出 ClassCastException 异常）；也可以使用带参构造函数，在创建时传入 Comparator 指定比较规则。
