斗地主

一个用集合实现斗地主发牌的小案例，跟着视频写，主要练习 List / Set / Map 的配合使用。

视频地址

初始化

先用最朴素的方式完成洗牌和发牌：不排序，把 54 张牌洗乱后，前 3 张留作底牌，其余 51 张轮流发给 3 个玩家（每人 17 张）。

排序

“初始化”版本已经能玩，但打印出来的手牌是乱序的。下面用三种思路解决排序问题，它们是三个独立的改进版本，一次只看一个即可（不要把它们写进同一个文件）：

思路一：权重映射 + TreeSet 自动排序——给每张牌分配一个权重数字，用 TreeSet 存放权重，遍历时再映射回牌面，天然有序。

思路二：牌面字符串 + 自定义比较器——仍然存字符串牌面，排序时把牌面翻译成权重（rankOf）和花色权重（suitRankOf），再交给 sort 的比较器。

UI 界面

略（对应视频后续内容，用 Swing 给每个玩家画出 17 张牌，点击牌可选中、出牌）。

面向对象

略（对应视频后续内容，把牌、玩家、牌型判断抽成 Card / Player / PokerType 等类，让代码更清晰）。

完善

略（对应视频后续内容，如加”叫地主/抢地主”、”出牌规则判断”、”电脑自动出牌”等功能）。
