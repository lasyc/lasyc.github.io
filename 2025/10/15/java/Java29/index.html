方法引用

方法引用是 Java 8 新增的语法，用于直接引用一个已经存在的方法。

使用背景：我们在调用某些方法时，有时需要传入一个函数式接口的实现类（比如 Comparator、Function），并实现它的抽象方法。但如果我们要写的这个逻辑，某个类里的方法已经实现了，那就不需要再写 Lambda 表达式，直接把这个方法当作参数传进去即可，这种写法就叫方法引用。

语法：类名::方法名（两个冒号）

提示：下面的示例大多是代码片段（只有核心语句），没有把 import 和类的框架都写全。复制到自己的项目里如果报”找不到符号”，通常就是缺 import，例如 java.util.ArrayList、java.util.List、java.util.Arrays、java.util.stream.Collectors 等，按报错提示补上即可。

成员方法引用

成员方法引用：对象名::方法名（对象已经存在时，通过对象来引用它的方法）

  • 其他类的对象：对象名::方法名，如 new Custom()::compare
  • 本类对象：this::方法名
  • 父类对象：super::方法名

类名成员方法引用

类名成员方法引用：类名::成员方法名（这里的成员方法不是静态方法）

说明：当使用 类名::成员方法 时，函数式接口抽象方法的第一个参数会作为调用这个成员方法的对象，其余参数依次传给该方法。所以被引用的成员方法有几个参数，函数式接口就比它多一个参数。

例如 map(String::toUpperCase)：map 接收的 Function 有一个参数（流里的每个字符串），toUpperCase 没有参数——第一个（也是唯一一个）参数作为调用者，等价于 str -> str.toUpperCase()。前面的 Integer::compareTo 也属于这一类：compareTo 有一个参数，Comparator 有两个参数，等价于 (o1, o2) -> o1.compareTo(o2)。
