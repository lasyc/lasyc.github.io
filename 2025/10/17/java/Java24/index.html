File 类

File 类是 Java 中操作文件最常用的类之一，表示一个文件或文件夹的路径。用法：根据文件路径来创建 File 对象，然后通过 File 对象来获取文件信息，或者操作文件。注意：File 不仅可以表示文件，也可以表示文件夹（毕竟文件夹也可以看做是一种特殊的文件），但 File 对象本身只是”路径的抽象”，并不代表磁盘上一定存在这个文件。

File 类的构造方法

构造方法 描述
File(String pathname) 根据文件路径创建 File 对象
File(String parent, String child) 根据父目录路径和文件名创建 File 对象
File(File parent, String child) 根据父目录 File 对象和文件名创建 File 对象

File 常用方法

File 类的常用方法可以分成三类：判断类（判断文件/文件夹的状态）、获取类（获取文件的各种信息）、操作类（创建、删除、重命名等）。

判断类

方法 描述
isDirectory() 判断当前文件是否是文件夹
isFile() 判断当前文件是否是文件
isHidden() 判断当前文件是否是隐藏文件
canRead() 判断当前文件是否可读
canWrite() 判断当前文件是否可写
canExecute() 判断当前文件是否可执行
exists() 判断当前文件是否存在
isAbsolute() 判断路径是否是绝对路径

注意：文件/文件夹不存在时，上面这些判断方法基本都会返回 false（不会报错），所以一般会先调用 exists() 确认存在再做其他判断。

Files 类

Files 是 JDK 7 新增的类，用于操作文件。相比于 File 类，Files 类需要配合 Path 来使用，功能更丰富、写法更方便，性能也更高。下面先看几个常用方法分类，注意这些方法大多需要传入一个 Path 对象（可以用 Path.of("...") 或 File.toPath() 获取）。

下面的方法都会接收一个 Path 对象作为参数，返回 boolean 表示检查结果。文件不存在时，除了 exists 返回 false 外，其他方法也大多返回 false。
