Java IO 缓冲流与转换流

发表于2025-10-19|更新于2026-09-12|后端语言基础Java
|总字数:2.1k|阅读时长:8分钟|浏览量:

缓冲流

前边学习了字节流和字符流，一共四个类：FileInputStream、FileOutputStream、FileReader 和 FileWriter。这四个类直接操作文件，读写效率较低、功能也比较欠缺。为了提高读写效率，Java 提供了缓冲流。缓冲流在字节流/字符流的基础上增加了一个缓冲区，读写数据时，先把数据读到缓冲区或写到缓冲区，攒够一批再真正操作文件，从而减少和磁盘的交互次数，提升效率。缓冲流也有四个类：BufferedInputStream、BufferedOutputStream、BufferedReader 和 BufferedWriter。

缓冲流并不是一种新的底层流，而是对已有流的”包装”。使用缓冲流时，需要把已有的基本流对象作为参数传入缓冲流的构造方法中。

补充：虽然字符流内部也带有缓冲区，但缓冲流的缓冲区大小可以自定义，而且缓冲流还额外提供了更方便的读写方式（如 readLine()），综合下来效率还是有提升的。

字节缓冲流 常用方法

BufferedInputStream 并不是 FileInputStream 的子类（它继承自 FilterInputStream，最终祖先和 FileInputStream 一样都是 InputStream），但因为构造时把 FileInputStream 传了进去，所以它拥有 InputStream 的所有读方法，同时还多了一层缓冲区。

BufferedOutputStream 同理，并不是 FileOutputStream 的子类，但拥有 OutputStream 的所有写方法。

BufferedWriter 同理（继承自 Writer），拥有 Writer 的所有写方法。

转换流

转换流属于字符流（继承自 Reader/Writer），作用是在字节流和字符流之间搭一座桥：把字节流包装成字符流，从而可以指定字符集来读写文本。转换流属于高级流，用来包装基本流。转换流有两个类：InputStreamReader（字节输入流转字符输入流）和 OutputStreamWriter（字符输出流转字节输出流）。

补充：JDK 11 之后，FileReader 和 FileWriter 的构造方法里也可以直接指定字符集，所以”读取文件”这种场景不一定要用转换流了；但在其他场景下（比如把一个网络输入流、内存字节流按指定编码转成字符流），转换流依然有它的价值。
