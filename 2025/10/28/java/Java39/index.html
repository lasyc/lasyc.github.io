反射

反射（Reflection）是 Java 提供的一种强大机制：程序在运行时可以动态地获取一个类的完整信息（构造方法、成员变量、成员方法、注解等），甚至可以绕过访问权限去调用私有成员、创建对象。

正常情况下我们是”写代码时就知道类里有什么”，而反射是”程序跑起来之后，通过 Class 对象反查类的结构”。Spring、MyBatis 等框架的底层大量使用反射，理解反射是看懂框架的基础。

获取 Class 对象

反射的入口是 Class 对象——一个 Class 对象就代表一个类。获取 Class 对象有三种方式：

  1. 通过 Class.forName("全类名")：在运行时把类名字符串加载成 Class 对象。常用于事先不知道具体类、类名来自配置文件/数据库的场景（比如 JDBC 早期加载驱动 Class.forName("com.mysql.cj.jdbc.Driver")），类名必须写全名（包名.类名）
  2. 通过 类名.class：编译时就知道是哪个类，直接拿它的 Class 对象。写法最简单、性能也最好
  3. 通过 对象.getClass()：在运行时通过已有的对象拿到它的 Class 对象（getClass() 是 Object 的方法，任何对象都能调）

提示：com.code_dog.demo01.Student 是示例类，练习时换成你自己项目里的类；Class.forName 会抛受检异常 ClassNotFoundException，需要 try-catch 或加 throws。

练习一：把任意对象保存到文件

需求：把任意对象保存到文件中，格式：属性名=属性值，每行一个属性（不管对象是什么类型，代码都不用改）。

动态代理

动态代理：在程序运行时动态地创建一个”代理对象”，由代理对象代替真实对象干活，并能在真实方法执行前后插入额外功能（打印日志、性能监控、权限校验等）。

为什么需要它？举个场景：某个对象的每个方法执行前都要打印日志。如果每个方法里都加一行打印代码，会重复很多遍；或者代码已经写好、不想改动原始类——这时就可以用动态代理，在不修改原代码的前提下给方法”加上”功能。

JDK 动态代理是基于接口的，核心类是 java.lang.reflect.Proxy 和接口 InvocationHandler，工作流程：

  1. 定义接口（真实对象和代理对象都要实现它，下文的 ProxyInter）
  2. 创建真实对象（Student），并让 Student 实现 ProxyInter 接口
  3. 用 Proxy.newProxyInstance(...) 创建代理对象，同时传入一个 InvocationHandler
  4. 调用代理对象的方法时，不会直接执行真实方法，而是先进到 InvocationHandler.invoke() 中；我们在 invoke() 里写额外逻辑（如打印日志），再通过 method.invoke(真实对象, 参数) 去调用真实方法

提示：需要 import java.lang.reflect.Proxy;、import java.lang.reflect.InvocationHandler;、import java.lang.reflect.Method;，还要 import java.time.LocalDateTime;（打印时间）和 import java.util.Arrays;。注意 Student 类必须 implements ProxyInter，否则 JDK 动态代理会报错。下面的代码写在某个测试类里。
