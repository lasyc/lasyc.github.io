MySQL 概述

概述

数据库（DataBase，DB）：数据库就是有组织地存储和管理数据的仓库。

MySQL：一个关系型数据库管理系统（Relational Database Management System，RDBMS）。注意 MySQL 本身并不是数据库，而是用来管理数据库的软件。

SQL：全称 Structured Query Language（结构化查询语言），是操作关系型数据库的标准语言。我们需要通过编写 SQL 语句来操作数据库中的数据。

数据库分类

数据库大致分为两类：关系型数据库（用二维表存储数据，通过 SQL 操作）和非关系型数据库（NoSQL，如 MongoDB 这种文档型数据库，不要求固定的表结构）。

说明：Hive 严格来说是构建在 Hadoop 上的数据仓库工具（提供类似 SQL 的 HiveQL），并不是传统意义上的关系型数据库，这里列出来供了解。

启动、停止

把 MySQL 注册成 Windows 服务后，用下面的命令启动/停止（需要以管理员身份打开命令提示符或 PowerShell）：

  1. 启动命令：net start 服务名
  2. 停止命令：net stop 服务名

说明：”服务名”是安装时设置的服务名称（默认一般是 MySQL 或 MySQL80），不记得的话可以按 Win + R 输入 services.msc 打开服务窗口查看。

数据模型

MySQL 采用客户端/服务端结构：客户端（命令行工具、图形化工具、Java 程序等）把 SQL 语句发给服务端，服务端中的 DBMS（DataBase Management System，数据库管理系统）负责解析 SQL 并执行相应操作，数据最终存储在磁盘上的文件中。

DBMS 按照关系模型来组织数据：每个数据库里都有一个或多个表，数据都存放在表中。表是二维表结构，每一行是一条记录（代表一个数据对象），每一列是一个字段（代表该对象的某个属性）；表与表之间可以通过外键建立关联。关系型数据库管理系统的核心数据结构就是这种”表”。
