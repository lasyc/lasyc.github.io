MySQL 存储过程进阶与触发器

发表于2025-11-26|更新于2026-09-12|后端数据库MySQL
|总字数:2.2k|阅读时长:9分钟|浏览量:

IF

IF 语句用于判断某个条件，并执行相应的语句

存储过程传参

参数类型 参数方向
IN 输入参数
OUT 输出参数
INOUT 输入输出参数

CASE

CASE 语句用于判断某个条件，并执行相应的语句

WHILE

WHILE 循环用于重复执行一段代码，直到条件为假

REPEAT

REPEAT 循环用于重复执行一段代码，直到条件为真但是 REPEAT 循环至少会执行一次

LOOP

LOOP 循环用于重复执行一段代码，直到条件为假但是 LOOP 必须配合 LEAVE 和 ITERATE 使用

  1. LEAVE 用于退出循环
  2. ITERATE 用于跳过当前循环，继续下一次循环

CURSOR（游标）

普通的变量一次只能存一个值。当查询结果有多行、需要逐行处理时（例如把查询出的每一行都插入另一张表），就要用到游标（CURSOR）：它像一个指针，可以一行一行地遍历查询结果

  1. 创建 CURSOR

    DECLARE 游标名 CURSOR FOR 查询语句;

  2. 打开 CURSOR

    OPEN 游标名;

  3. 获取 CURSOR 的结果

    FETCH 游标名 INTO 变量;

  4. 关闭 CURSOR

    CLOSE 游标名;

条件处理（Handler）

条件处理程序（Handler）用来处理 SQL 运行过程中出现的错误或特殊状态，作用类似 Java 的 try-catch：当语句出错（或取不到数据）时，可以选择忽略错误继续执行，也可以提前退出。

  1. 创建条件处理程序

    DECLARE {CONTINUE | EXIT} HANDLER FOR 错误条件 处理语句;

  2. 处理方式（二选一）：

    • CONTINUE：发生错误/状态后忽略它，继续执行后面的语句
    • EXIT：发生错误/状态后立即退出当前的 BEGIN…END 块（存储过程/函数）

  3. 错误条件（多个用逗号分隔）：

    • SQLSTATE '状态码'：匹配指定的 SQLSTATE 状态码，如 '02000' 表示”没有找到数据”
    • SQLWARNING：匹配所有以 01 开头的警告
    • NOT FOUND：匹配所有以 02 开头的状态（典型就是 FETCH 游标取不到数据）
    • SQLEXCEPTION：匹配除警告、NOT FOUND 以外的其他所有错误

存储函数

存储函数和存储过程类似，但是存储函数返回一个值，且存储函数只能有输入参数

触发器

触发器（Trigger）是一种与表关联的数据库对象：在指定的表上执行 INSERT、UPDATE、DELETE 之前（BEFORE）或之后（AFTER），触发器会自动执行一段 SQL，不需要手动调用

使用触发器

  1. 创建触发器

    CREATE TRIGGER 触发器名 [BEFORE | AFTER] [INSERT | UPDATE | DELETE] ON 表名 FOR EACH ROW BEGIN 触发器体; END;

  2. 查看触发器

    SHOW TRIGGERS;

  3. 删除触发器

    DROP TRIGGER [表名.]触发器名;

练习

创建 user_log 表，记录用户操作日志

总结

  1. 视图（VIEW）：数据库中的虚拟表，本身不存数据，查询时动态从基础表取数
  2. 存储过程（PROCEDURE）：事先封装好的一组 SQL，用 CALL 调用，可接收 IN/OUT/INOUT 参数、包含流程控制
  3. 存储函数（FUNCTION）：与存储过程类似，但必须返回一个值，且只有输入参数，常用于封装计算逻辑
  4. 触发器（TRIGGER）：与表绑定，在 INSERT / UPDATE / DELETE 前后自动触发执行
