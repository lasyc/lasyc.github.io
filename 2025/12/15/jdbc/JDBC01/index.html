数据的持久化

持久化：把数据保存到非易失性存储设备（如硬盘）中，以便之后继续使用。数据持久化意味着将内存中的数据保存到硬盘上，而持久化的实现过程大多通过关系型数据库完成

Java 中的数据存储技术

在 Java 中，数据库存取技术可以分为以下几类：

  1. JDBC 直接访问
  2. JDO 技术
  3. 第三方框架：Hibernate、MyBatis 等

JDBC 是 Java 访问数据库的基础，JDO、Hibernate、MyBatis 等只是在 JDBC 基础上进行了封装，丰富了功能

JDBC 介绍

JDBC（Java Database Connectivity）是一个独立于特定数据库管理系统、通用的 SQL 数据库存取和操作的公共接口（API），定义了用来访问数据库的 Java 类库（java.sql，javax.sql），使用这些类库可以通过标准的方法来访问数据库

JDBC 为访问不同的数据库提供了统一途径，使开发者无需关心不同数据库之间的差异。操作不同的数据库时，只需要引入对应的驱动即可——驱动就是各数据库厂商根据 JDBC 标准接口编写的具体实现类

JDBC 体系结构

  1. 面向应用的 API：标准化接口，供开发人员使用，无需关注内部的细节
  2. 面向数据库的 API：遵循标准化接口，供数据库厂商使用，用于开发对应数据库的驱动

JDBC 程序编写步骤

  1. 加载驱动：下载对应的驱动 jar 包，加载驱动
  2. 创建连接：创建 Connection 对象
  3. 构造 SQL 语句：创建 Statement 对象
  4. 执行 SQL 语句
    • 查询语句：使用 ResultSet 接收查询结果，用完后关闭 ResultSet
  5. 关闭资源：依次关闭 ResultSet、Statement、Connection 对象
