ResultSet

当我们执行查询操作时，会返回一个结果集 ResultSet，其中保存了 SQL 查询出来的数据，为了方便查看数据，我们需要将数据进行转换，这时候就要引入 ORM 编程思想

ORM（Object Relational Mapping）意思是：

  1. 一个表对应一个类
  2. 一条记录对应一个对象
  3. 一个字段对应一个属性

而此时就涉及到了 MySQL 中字段的类型与 Java 中数据类型的映射关系，不同版本的数据库驱动映射关系可能不一致

MySQL Java
BIT Boolean
TINYINT Byte
SMALLINT Short
INTEGER Integer
BIGINT Long
CHAR、VARCHAR、LONGVARCHAR String
BINARY、VARBINARY byte[]
DATE java.sql.Date
TIME java.sql.Time
DATETIME java.time.LocalDateTime
TIMESTAMP java.sql.Timestamp

我们可以尝试编写一个简单的查询语句，只是针对于 tb_user 这个表

在上边的代码中，我们已知返回 id、username、password、createTime 四个字段，因此可以执行四次 resultSet.getXXX() 方法来获取每列的值，但是如果我们不知道 SQL 语句中具体查询了哪几列呢？

这是，我们可以通过 ResultSet 来获取元数据，在元数据中，保存了具体的列数和列名

新的问题出现了：我们虽然能拿到列的个数和值，但不知道每一列对应哪个属性、值该设置到哪个属性上。

前面提到过，列名和属性名是存在对应关系的，如 id → id、username → username、create_time → createTime。因此可以先获取列名，再通过反射把值设置到对应的属性中

此时，执行程序时会报错：java.lang.NoSuchFieldException: create_time，因为需要先把 create_time 转成 createTime 才能匹配到属性，这时有两种办法：

  1. 在 SQL 中给列起别名（如 create_time AS createTime），同时用 getColumnLabel 代替 getColumnName 获取列名——前者获取的是别名

  2. 自己编写一个方法，把 xxx_xxx 下划线命名转为 xxxXxx 小驼峰命名

但上面的方法只能查询 tb_user、返回 User，太局限。返回值不应仅限于某一个类，所以可以借助泛型 + 反射来动态创建对象：传入哪个类，就返回哪个类型的对象

以上的查询通用代码已经接近完美，但是只能返回一个对象，此时再使用 List<T> 来接收结果并返回，便可以实现查询多个结果的功能
