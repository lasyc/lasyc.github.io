Blob

Blob（Binary Large Object，二进制大对象）是 MySQL 中用来存储大量二进制数据的类型（如图片、文件内容），可以容纳不同大小的数据

通常使用 PreparedStatement 操作 Blob：通过 ? 占位符配合 setBlob()，可以把整个文件流作为参数传入。用 Statement 拼接 SQL 来处理二进制流比较麻烦，所以一般不用它操作 Blob

在 MySQL 中 Blob 有四种类型，除了可容纳的数据大小不同以外，其余特性是相同的

类型 大小（字节）
TinyBlob 255
Blob 65K
MediumBlob 16M
LongBlob 4G

Blob 类型常用于保存文件（把文件转为二进制存入数据库）。但如果文件过大，会明显影响数据库的性能，所以实践中更多是把大文件保存在服务器的文件夹中，只在数据库里存一个文件路径字符串

在 MySQL 中上传大文件时，有时会提示”文件过大”：这是 max_allowed_packet 参数限制了单次可传输的最大数据包（默认值因版本而异，如 MySQL 8.0 默认 64MB）。可以调大该参数（修改后需重启 MySQL 生效），再上传大文件
