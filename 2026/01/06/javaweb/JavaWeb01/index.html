HTML 标签的介绍

HTML 标签 是 HTML 文档的构建块，用于定义网页中的元素

标签按照格式分为：单标签和双标签

单标签：如<br />、<hr />、<img src="xxx" /> 等只有开始标签，没有结束标签
双标签：如<p></p>、<div></div>、<h1></h1> 等，由开始标签和结束标签组成

个别标签还拥有属性，如 <img src="xxx" /> 中 src 属性用于指定图片的源文件

个别标签还拥有事件，如 <button onclick="xxx()"></button> 中 onclick 属性用于指定按钮点击时执行的 JavaScript 代码

标签的语法

  1. 双标签内可以嵌套其他标签，但是不可以交叉嵌套：

    • 正确：<div><p>文字</p></div>
    • 错误：<div><p>文字</div></p>

  2. 双标签必须关闭：

    • 正确：<div>文字</div>
    • 错误：<div>文字

  3. 单标签也需要关闭：

    • 正确：<br />
    • 错误：<br>

  4. 标签中的属性必须使用引号括起来：

    • 正确：<img src="xxx" />
    • 错误：<img src=xxx />

  5. 注释不能嵌套：

    • 正确：<!-- 注释 -->
    • 错误：<!-- <!-- 注释 --> -->

表格标签

table 标签定义了 HTML 表格

一个 HTML 表格由一个 table 元素和一个或多个 tr、th 和 td 元素组成：

  • tr：定义表格行
  • th：定义表头单元格
  • td：定义普通单元格

HTML 表格还可以包含以下元素：

  • caption：定义表格标题
  • colgroup：定义表格列
  • thead：定义表格头部
  • tfoot：定义表格尾部
  • tbody：定义表格的主体

colspan 属性用于合并列，rowspan 属性用于合并行

表单格式化

使用 table 标签来格式化表单

表单提交细节

通过 action 属性来指定表单提交的目标地址，通过 method 属性来设置表单提交方式

method 请求分为两种：分别是 get 和 post

当使用 get 方式提交表单时，参数会以 name=value 的格式拼接到 url 中，且参数长度有限制

当使用 post 方式提交表单时，参数会放在请求体中（默认编码为 application/x-www-form-urlencoded，格式同样是 name=value），不会暴露在 URL 上，且参数长度没有限制

  1. 需要提交数据的表单控件必须包含在 form 标签内，否则不会被提交
  2. 需要提交数据的表单控件必须包含 name 属性，否则不会被提交
  3. 单选框、复选框、option 标签必须包含 value 属性

CSS 技术

CSS 技术介绍

HTML 是一种用于描述网页内容的标记语言，CSS 是一种用于描述网页样式的样式表语言

在线文档

CSS 语法规则

  1. 选择器：用于匹配元素
  2. 属性：用于描述元素样式
  3. 值：属性的取值

CSS 与 HTML 的结合方式

  1. 通过 style 属性写在标签中，称为行内样式
  2. 通过 style 标签写在 head 中，称为内部样式
  3. 创建 .css 文件，通过 link 标签引入，称为外部样式

结合方式一

结合方式二

使用行内样式时如果样式过多，全部写在标签中会显得代码很乱；并且多个标签的样式相同时，代码需要写很多次。因此，我们可以使用内部样式

使用内部样式需要定义选择器，通过选择器来指定哪些标签采用该样式。CSS 选择器可以分为五类：

  1. 简单选择器（根据名称、id、类来选取元素）
  2. 组合器选择器（根据它们之间的特定关系来选取元素）
  3. 伪类选择器（根据特定状态选取元素）
  4. 伪元素选择器（选取元素的一部分并设置其样式）
  5. 属性选择器（根据属性或属性值来选取元素）

结合方式三

对于内部样式，虽然解决了行内样式的缺点，但是也存在不足：所编写的 CSS 代码仅在当前 HTML 文件中生效，并且将 CSS 代码和 HTML 代码混合在一起，使得代码的维护性变得非常困难。因此可以使用外部样式

外部样式就是将 CSS 代码保存在单独的文件中，并引入到 HTML 文件中

标签名选择器

上面提到了类选择器，其实 CSS 中还有很多种选择器，比如标签选择器、ID 选择器、属性选择器等。

标签选择器，就是通过标签名来选择元素，比如 div、span、p 等等。

当以标签为单位来设置样式时，可以使用标签选择器

ID 选择器

标签选择器会使所有标签都生效，但是如果想区分开来，可以使用ID 选择器

通过 # + id 来定义 ID 选择器，在标签中通过 id 属性来指定选择器名称

但是 id 属性的值不可以重复，因此使用 ID 选择器只能将样式应用于一个标签，多个标签不可复用

类选择器

类选择器相比于ID 选择器，可以重复使用，并且类选择器可以添加多个类名，多个类名之间用空格隔开

组合选择器

组合选择器由多个选择器组合而成，分为：

选择器 示例 示例描述
后代选择器 (空格) div p 选择 <div> 元素内的所有 <p> 元素
子选择器 (>) div > p 选择其父元素是 <div> 元素的所有 <p> 元素
相邻兄弟选择器 (+) div + p 选择所有紧随 <div> 元素之后的 <p> 元素
通用兄弟选择器 (~) p ~ ul 选择前面有 <p> 元素的每个 <ul> 元素
