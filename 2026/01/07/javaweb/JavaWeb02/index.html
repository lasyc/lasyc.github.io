表单与其他标签

表单标签

form 标签用于为接收用户输入创建 HTML 表单

属性 值 描述
accept-charset 字符集 规定提交表单时要使用的字符编码
action URL 规定提交表单时将表单数据发送到哪里
autocomplete on、off 规定表单是否应启用自动完成功能
enctype application/x-www-form-urlencoded、multipart/form-data、text/plain 规定在向服务器提交表单数据时，应该如何对表单数据进行编码
method get、post 规定发送表单数据时使用的 HTTP 方法
name 文本 规定表单的名称
novalidate novalidate 规定提交表单时不应验证表单
rel alternate、nofollow、noopener 等 规定链接资源和当前文档之间的关系
target _blank、_self、_parent、_top 规定在何处显示提交表单后收到的响应

form 元素可以包含以下一个或多个表单元素：

  • input：输入框标签
  • textarea：多行文本输入框标签
  • button：按钮标签
  • select：下拉列表标签
  • option：选项标签
  • optgroup：选项组标签
  • fieldset：表单字段集标签
  • label：表单项目标题标签
  • output：表单输出标签

其中 input 标签用于创建输入框，可以根据属性 type 来设置输入框的类型

type 说明
button 定义可点击的按钮（主要与 JavaScript 一起使用以激活脚本）
checkbox 定义复选框
color 定义颜色选择器（拾色器）
date 定义日期控件（年月日，无时间）
datetime-local 定义日期和时间控件（年、月、日、时间，无时区）
email 定义用于输入电子邮件地址的字段
file 定义文件选择字段和“浏览”按钮（用于文件上传）
hidden 定义隐藏的输入字段
image 定义图像作为提交按钮
month 定义月份和年份控件（无时区）
number 定义用于输入数字的字段
password 定义密码字段
radio 定义单选按钮
range 定义范围控件（如滑块控件）
reset 定义重置按钮
search 定义用于输入搜索字符串的文本字段
submit 定义提交按钮
tel 定义用于输入电话号码的字段
text 默认定义单行文本字段
time 定义输入时间的控件（无时区）
url 定义用于输入 URL 的字段
week 定义周和年控件（无时区）

表单提交细节

通过 action 属性来指定表单提交的目标地址，通过 method 属性来设置表单提交方式

method 请求分为两种：分别是 get 和 post

当使用 get 方式提交表单时，参数会以 name=value 的格式拼接到 url 中，且参数长度有限制

当使用 post 方式提交表单时，参数会放在请求体中（默认编码为 application/x-www-form-urlencoded，格式同样是 name=value），不会暴露在 URL 上，且参数长度没有限制

  1. 需要提交数据的表单控件必须包含在 form 标签内，否则不会被提交
  2. 需要提交数据的表单控件必须包含 name 属性，否则不会被提交
  3. 单选框、复选框、option 标签必须包含 value 属性

其他标签

在 HTML 中，除了上述一些标签，还有很多很多标签，如：div、span、p、button 等，具体可查看在线文档

div 和 span 标签是容器标签，用于页面布局：div 是块级元素，在页面中独占一行；span 是行内元素，一行中可以显示多个
