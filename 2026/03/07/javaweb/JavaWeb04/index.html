JavaScript 介绍

JavaScript 是一种运行在浏览器上的脚本语言

JavaScript 和 HTML 代码的结合

方式一

使用 <script> 标签，将 js 代码编写到 html 文件中

方式二

将 js 代码编写到 js 文件中，并引入 html 文件中

变量

js 是一种弱类型的语言，变量声明时不需要指定变量的类型

基本数据类型：

数据类型 描述
Number 数值
String 字符串
Boolean 布尔值
Null 空值
Undefined 未定义
Symbol 符号

引用数据类型：

数据类型 描述
Object 对象
Array 数组
Function 函数
Date 日期
RegExp 正则表达式

因为 js 定义变量时不需要声明数据类型，所以当我们想要查看变量的数据类型时，可以使用 typeof 运算符

在 ES5 中可以使用 var 声明变量，ES6 又新增了 let 和 const 两种声明方式

  • let 声明的变量只在当前作用域有效，在当前作用域外无法访问
  • const 声明的变量必须初始化，且不能被重新赋值

关系运算符

同 Java 一样，关系运算符也分为等于、大于、小于、大于等于、小于等于、不等于

运算符 示例 描述
== a == b 等于
> a > b 大于
< a < b 小于
>= a >= b 大于等于
<= a <= b 小于等于
!= a != b 不等于

但是 js 中，比 Java 多了一个 === 运算符，用于判断两个值是否相等，且要求类型也必须相同

运算符 示例 描述
=== a === b 严格等于
!== a !== b 严格不等

逻辑运算符

也同 Java 语言一样，逻辑运算符也分为与、或、非三种

运算符 示例 描述
&& true && true true
| | true || false true
! !true false

并且在 js 中，任何值都可以作为布尔值来使用：除了 false、0、null、undefined、NaN、空字符串 以外，其余的值都相当于 true

js 中的逻辑运算符的返回值也和 Java 中的有所区别

  1. &&：逻辑与，返回第一个为 false 的值，否则返回最后一个值
  2. ||：逻辑或，返回第一个为 true 的值，否则返回最后一个值

数组

数组的定义

因为 js 是弱数据类型，所以数组的元素可以是任意类型

函数

函数的定义一

使用 function 关键字定义函数

函数的定义二

将函数作为一个值，赋给变量

可以改写成箭头函数

函数重载

在 js 中不存在函数重载的概念。因为函数本质上也是一种值，可以像变量一样被赋值，所以如果定义了多个同名函数，就相当于给同一个变量赋了多次值，最终只会保留最后一个函数

函数的隐藏参数 arguments

在 js 的函数中，我们可以通过 arguments 对象来访问函数接收到的所有实参
