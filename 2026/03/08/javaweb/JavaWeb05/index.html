Web 前端 JavaScript 事件、DOM 与正则

JS 中的事件

事件就是用户行为，比如点击、鼠标移动、键盘按下等

事件分为：

  1. 鼠标事件
  2. 键盘事件
  3. 框架/对象事件
  4. 表单事件
  5. 剪切板事件
  6. 打印事件
  7. 拖动事件
  8. 多媒体事件
  9. 动画事件
  10. 过渡事件
  11. 其他事件

想要通过对应的行为触发对应的事件，首先我们要先注册事件，分为静态注册和动态注册

  • 静态注册：在编写 HTML 标签时，通过 onXXX 属性来注册事件，如：onclick="clickHandler()"
  • 动态注册：需要先获取标签对象，然后调用 addEventListener() 方法来注册事件，如：button.addEventListener("click", clickHandler);

onload

onload 是一个事件，当页面加载完成后，会触发该事件

onclick

onclick 是一个事件，当用户点击某个元素时，会触发该事件

onfocus 和 onblur

onfocus 和 onblur 是 HTML 中的事件属性，用于处理元素获得焦点和失去焦点时触发的事件

onchange

onchange 事件在元素的值发生改变时触发：对于文本框，通常是在修改内容并失去焦点后触发；对于 select、checkbox 等元素，则是在选择变化时立即触发

onsubmit

onsubmit 属性规定当提交表单时运行的脚本

DOM 模型

DOM（Document Object Model，文档对象模型）是 HTML 和 XML 文档的编程接口，由 W3C（World Wide Web Consortium，万维网联盟）定义。DOM 将 HTML 或 XML 文档视为一棵树结构（DOM 树），树中的每个节点（node）都对应文档中的一个元素（element）

Document 对象

Document 对象表示 HTML 文档，它是 DOM 树中的根节点

通过 Document 对象，我们可以访问 HTML 文档中的所有元素，例如获取 HTML 文档的标题、链接、表格、图像等等。

其中的每一个 DOM 元素都是一个对象

常用方法

document 对象提供了以下常用的方法：

方法 描述
getElementById(id) 返回带有指定 id 的元素（id 唯一，通常只有一个）
getElementsByTagName(tagName) 返回带有指定标签名的所有元素
getElementsByClassName(className) 返回带有指定 class 的所有元素
getElementsByName(name) 返回带有指定 name 的所有元素
getElementsByTagNameNS(namespaceURI, localName) 获取指定命名空间下的指定标签名的所有元素
createElement(tagName) 创建一个元素节点
querySelector(selector) 返回匹配指定 CSS 选择器的第一个元素
querySelectorAll(selector) 返回匹配指定 CSS 选择器的所有元素

getElementById

getElementById 方法用于获取指定ID的元素，因为 id 属性是唯一的，所以 getElementById 方法返回的元素只有一个

getElementsByName

getElementsByName 方法用于获取指定 name 的元素。因为 name 属性可以重复，所以会返回一个 NodeList 对象（类数组），其中包含所有匹配的元素

getElementsByTagName

getElementsByTagName 方法用于获取指定标签名的元素，同理也会返回一个 HTMLCollection 对象，该对象包含所有匹配的元素

DOM 对象常用属性和方法

方法 作用
appendChild(child) 添加子节点
insertBefore(newNode, referenceNode) 在指定节点之前插入新的节点
replaceChild(newChild, oldChild) 替换子节点
属性 作用
childNodes 获取所有子节点
firstChild 获取第一个子节点
lastChild 获取最后一个子节点
parentNode 获取父节点
nextSibling 获取下一个兄弟节点
previousSibling 获取上一个兄弟节点
className 获取或设置元素的 class 属性
innerHTML 获取或设置元素内部的 HTML 内容
innerText 获取或设置元素的纯文本内容

正则表达式对象

正则表达式是 JavaScript 中的一个内置对象，用于匹配字符串，并提供了一系列方法，用来判断字符串是否符合某种模式或提取匹配结果

正则表达式的创建方式有两种：

  1. 构造函数方式：使用 new RegExp(pattern, modifiers) 创建正则表达式对象，如：const reg = new RegExp("[0-9]", "g");
  2. 字面量方式：使用 /pattern/modifiers 直接创建，如：const reg = /[0-9]/g;

正则表达式对象提供了以下方法：

方法 描述
exec() 匹配字符串，返回匹配结果
test() 匹配字符串，返回布尔值
