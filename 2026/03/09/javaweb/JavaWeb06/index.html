jQuery 介绍

jQuery 是一个开源的 JavaScript 库，它简化了 JavaScript 的开发，并使 JavaScript 更易用。

jQuery 初体验

jQuery 核心函数

$ 函数是 jQuery 的核心函数，用于创建 jQuery 对象。根据传入的参数不同，$ 函数会返回不同类型的对象。

参数类型 功能 示例
CSS 选择器字符串 选择 DOM 元素 $('div')
HTML 字符串 创建新 DOM 元素 $('<p>Hello</p>')
DOM 元素/数组 封装为 jQuery 对象 $(document.body)
函数 文档加载就绪回调 $(function(){})
jQuery 对象 复制 jQuery 对象 $(existingjQueryObj)
选择器 + 上下文 在上下文中选择 $('li', 'ul')
无参数/无效参数 空 jQuery 对象 $()
window/document 对象 操作窗口/文档 $(window).scrollTop()

区分 DOM 对象和 jQuery 对象

通过 document.getElementByXXX() 获取的是 DOM 对象，通过 $('xxxx') 获取的是 jQuery 对象。

jQuery 对象的本质

jQuery 对象本质上就是 DOM 节点的集合，jQuery 集合中的每个元素都是 DOM 节点。

jQuery 对象和 DOM 对象使用区别

jQuery 对象和 DOM 对象在方法和属性上有所不同：jQuery 对象只能调用 jQuery 的方法（如 text()、css()），不能直接调用 DOM 的方法（如 innerText）；反之，DOM 对象也只能调用 DOM 的属性和方法，不能直接调用 jQuery 的方法。

相互转换

我们可以通过 $(DOM对象) 将 DOM 对象转为 jQuery 对象，或者通过 jQuery对象[0] 将 jQuery 对象转为 DOM 对象。

jQuery 基础选择器

选择器 描述 示例
元素选择器 选取所有指定元素 $(“p”)
ID 选择器 选取指定 ID 的元素 $(“#para1”)
类选择器 选取同一类 CSS 的元素 $(“.test”)

层级选择器

选择器 描述 示例
后代选择器 选取匹配元素内部所有的后代元素 $(“div p”)
子选择器 选取父元素下的所有直接子元素 $(“div > p”)
兄弟选择器（相邻） 选取相邻的兄弟元素 $(“div + p”)
兄弟选择器（所有） 选取所有兄弟元素 $(“div ~ p”)

筛选选择器

基本

选择器 描述 示例
:first 选取第一个元素 $(“p:first”)
:last 选取最后一个元素 $(“p:last”)
:even 选取索引为偶数的元素（索引从 0 开始） $(“p:even”)
:odd 选取索引为奇数的元素（索引从 0 开始） $(“p:odd”)
:eq() 选取索引为 n 的元素 $(“p:eq(1)”)
:gt() 选取索引大于 n 的元素 $(“p:gt(1)”)
:lt() 选取索引小于 n 的元素 $(“p:lt(1)”)
:not() 选取不匹配指定选择器的元素 $(“p:not(.cls)”)
:header 选取所有标题元素 $(“:header”)
:animated 选取所有正在执行动画的元素 $(“:animated”)

内容

选择器 描述 示例
:contains() 选取包含指定文本的元素 $(“:contains(‘Hello’)”)
:empty 选取所有没有子元素的元素 $(“:empty”)
:has() 选取包含指定子元素的元素 $(“:has(p)”)
:parent 选取所有有子元素的元素 $(“:parent”)

属性

选择器 描述 示例
[attr] 属性存在 $(“[href]”)
[attr=val] 属性等于 val $(“[type=checkbox]”)
[attr^=val] 属性以 val 开头 $(“[src^=http]”)
[attr$=val] 属性以 val 结尾 $(“[src$=.png]”)
[attr*=val] 匹配属性包含 val $(“[class*=container]”)

表单

选择器 描述 示例
:input 匹配所有 input、textarea、select 和 button 元素 $(“:input”)
:text 所有 type=”text” 的 input 元素 $(“:text”)
:password 所有 type=”password” 的 input 元素 $(“:password”)
:radio 所有 type=”radio” 的 input 元素 $(“:radio”)
:checkbox 所有 type=”checkbox” 的 input 元素 $(“:checkbox”)
:submit 所有 type=”submit” 的 input 元素 $(“:submit”)
:reset 所有 type=”reset” 的 input 元素 $(“:reset”)
:button 所有 type=”button” 的 input 元素 $(“:button”)
:image 所有 type=”image” 的 input 元素 $(“:image”)
:file 所有 type=”file” 的 input 元素 $(“:file”)

状态

选择器 描述 示例
:hidden 选取所有不可见的元素 $(“:hidden”)
:visible 选取所有可见的元素 $(“:visible”)
:enabled 选取所有可用的元素 $(“:enabled”)
:disabled 选取所有不可用的元素 $(“:disabled”)
:focus 选取所有聚焦的元素 $(“:focus”)
:selected 选取所有选中的元素 $(“:selected”)
:checked 选取所有被选中的元素 $(“:checked”)
