CSS 样式操作

jQuery 动画操作

方法 描述

hide() 隐藏元素
toggle() 切换显示或隐藏元素
fadeIn() 通过淡入（逐渐增加不透明度）显示隐藏的元素
fadeOut() 通过淡出（逐渐减少不透明度）隐藏可见的元素
fadeTo() 将元素逐渐变为指定的透明度
fadeToggle() 在淡入和淡出效果之间进行切换

事件的冒泡

事件冒泡是指：当一个元素上的事件被触发时，事件会逐级向它的父元素传播，直到 document。我们可以通过 event.stopPropagation() 来阻止事件继续向上冒泡。

jQuery 事件对象

jQuery 事件对象 event 是一个对象，封装了事件触发时浏览器提供的所有信息。如果事件处理函数没有参数，则 event 可以省略；如果函数需要参数，则 event 必须放在参数列表的第一个位置。
