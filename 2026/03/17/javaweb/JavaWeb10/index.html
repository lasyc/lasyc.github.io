Java Web XML 语法与 dom4j 解析

XML 简介

什么是 XML

XML（Extensible Markup Language，可扩展标记语言）是一种用于存储和传输数据的结构化语言。XML 的主要作用是传输数据，常被用作客户端与服务器之间、不同程序之间交换数据的格式，在 HTML、CSS、JavaScript、PHP、ASP、JSP 等 Web 技术中都有应用。

作用

XML 是一种用于存储和传输数据的结构化语言。

XML 也可以作为配置文件使用

XML 语法

文档声明

XML 文档声明必须放在文档的最开头，用于声明文档的版本和编码方式。

文档注释

XML 注释用于对 XML 文档中的内容进行说明和描述，写法与 HTML 注释相同。

元素（标签）

XML 元素是构成 XML 文档的基本单位，用于描述 XML 文档中的内容。同 HTML 元素一样，XML 元素也分为单标签（自闭合标签）和双标签，也可以拥有属性和子元素。

但是 XML 元素没有固定的元素名，开发人员可以自定义元素名，同时需要遵循以下命名规则：

  1. 元素名称区分大小写
  2. 元素名称必须以字母或下划线开头
  3. 元素名称不能以 xml 开头（不区分大小写，如 XML、Xml 等）
  4. 元素名称可以包含字母、数字、连字符、下划线和句点
  5. 元素名称不能包含空格

属性

XML 元素可以拥有属性，属性用于为元素提供额外的信息。

尽可能使用元素来描述数据，而不是使用属性。

特殊字符

同 HTML 一样，在 XML 中使用特殊字符时，需要使用实体引用。

如果存在大量的特殊字符，可以使用 CDATA 节来处理。CDATA 节是一个包含特殊字符的文本块，其中的内容不会被 XML 解析器解析。CDATA 节以 <![CDATA[ 开始，以 ]]> 结束。

XML 解析

XML 解析器用于解析 XML 文档，它可以将 XML 文档解析为树结构，并返回解析结果。

在 Java 中，可以使用 DOM 和 SAX 解析 XML 文档，但是这两种技术操作起来比较繁琐。

  1. DOM（Document Object Model）技术是 W3C 组织推荐的 XML 解析技术，它会将整个 XML 文档加载到内存中形成一棵树，几乎所有的编程语言都提供了 DOM 解析器
  2. SAX（Simple API for XML）技术采用事件驱动的方式解析 XML，边读取边解析，内存占用较小，它是行业共同制定的规范，并非 Java 官方技术

我们也可以直接使用第三方解析库 dom4j 来完成 XML 解析，使用起来更加方便。
