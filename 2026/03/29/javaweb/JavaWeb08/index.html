JSP

JSP（Java Server Pages）是一种动态网页技术。

早期的 HTML 页面只能静态显示数据。如果想要动态更新数据，就只能在后端通过字符串拼接绘制 HTML 页面，然后传给前端展示。

JSP 允许在 HTML 中嵌入 Java 代码，从而实现动态网页，让 HTML 中的数据实现动态更新的效果。

JSP 本质

JSP 本质上是一个 Java 类，会被容器编译成 .class 文件后再运行。JSP 生成的类继承了 HttpJspBase 类，而 HttpJspBase 类又继承了 HttpServlet 类，所以 JSP 本质上是 HttpServlet 的一个子类。在 JSP 内部，其实也是通过 resp 将 HTML 拼接成字符串返回给前端，只不过不用我们自己拼接字符串了，JSP 会自动完成拼接。

语法

Page 指令

Page 指令用于指定 JSP 页面的属性

  1. language: 指定 JSP 页面的脚本语言
  2. contentType: 指定 JSP 页面的内容类型
  3. pageEncoding: 指定 JSP 页面的编码
  4. import: 指定导入的类
  5. autoFlush: 指定是否自动刷新
  6. buffer: 指定缓冲区大小
  7. errorPage: 错误页面
  8. isErrorPage: 是否是错误页面
  9. session: 是否使用 session
  10. extends: 指定继承的父类

注释

在 JSP 中，有三种注释方式：

  1. HTML 注释：<!-- 注释内容 -->
  2. JSP 注释：<%-- 注释内容 --%>
  3. Java 注释：<% /* 注释内容 */ %>

内置对象

因为 JSP 本质就是一个 Servlet，所以 JSP 中内置了和 Servlet 中一样的对象。

对象 描述
request HttpServletRequest 类的实例，代表 HTTP 请求的对象，包含客户端发送到服务器的信息，如表单数据、URL参数等
response HttpServletResponse 类的实例，代表 HTTP 响应的对象，用于向客户端发送数据和响应
out JspWriter 类的实例，用于向客户端输出文本内容的对象，通常用于生成HTML
session HttpSession 类的实例，代表用户会话的对象，可用于存储和检索用户特定的数据，跨多个页面
application ServletContext 类的实例，代表 Web 应用程序的上下文，可以用于存储和检索全局应用程序数据
config ServletConfig 类的实例，包含有关当前 JSP 页面的配置信息，例如初始化参数
pageContext PageContext 类的实例，提供对 JSP 页面所有对象以及命名空间的访问
page 类似于 Java 类中的 this 关键字，代表当前 JSP 页面的实例，可以用于调用页面的方法
exception exception 类的对象，代表发生错误的 JSP 页面中对应的异常对象，用于处理 JSP 页面中的异常情况，可用于捕获和处理页面中发生的异常，需要在 JSP 中开启 isErrorPage="true"

域对象

在上述九个对象中，有四个域对象：request、session、application、pageContext

这四个域对象都提供了 getXXX 和 setXXX 方法，可以像 Map 一样存取数据。

作用范围：

对象 作用范围
request 一次请求范围（从发送请求到接收响应）
session 一次会话，打开浏览器直至关闭
application 一次应用，项目启动直至关闭
pageContext 一次页面，当前 JSP 页面

范围从小到大依次是：pageContext < request < session < application

out 和 response.getWriter()

out 和 response.getWriter() 都是 JSP 页面中用于向客户端输出内容的对象。当我们同时使用这两个对象输出内容时，out 输出的内容会追加到 response.getWriter() 输出的内容之后。

实际上，out 底层也是通过 response.getWriter() 获取的输出流。两者的区别在于：out 是 JSP 的内置对象，由 JSP 容器创建并管理；而 response.getWriter() 每次调用都会返回一个新的 PrintWriter 对象，两者并不是同一个对象。

在 JSP 页面中，默认使用 out 来输出内容。因此当我们在 JSP 页面中输出内容时，建议统一使用 out 对象，与 JSP 保持一致，避免页面结构错乱。

在 out 对象中，存在两个方法：write() 和 print()。在输出字符串时，两者没有任何区别；但是当输出数值时，write() 会将该数值当作字符编码，输出对应的字符，而 print() 会将数值转换成对应的数字字符串。

静态包含

当多个页面存在相同内容时，比如页头、页脚，我们可以将这部分代码抽取为一个单独的页面，然后通过 <%@ include file="..." %> 指令引入到需要使用的页面中。

动态包含

动态包含与静态包含实现的效果相同，只是实现方式不同：动态包含需要使用 <jsp:include page="xxx.jsp" /> 标签来实现。

静态包含会将公共文件和主体文件作为一个整体，只会生成一个 Servlet 文件；而动态包含会为公共文件单独生成 Servlet 文件，即生成多个 Servlet 文件，然后通过 JspRuntime.include(request, response, page) 方法将公共文件包含到主体文件中。

动态包含的底层调用了 JspRuntime.include(request, response, page)，把自己的 request、response、page 传递给公共文件，因此当公共文件通过 out 输出时，使用的其实是主体文件的输出流，这样才能把各文件的内容整合到一起显示在页面上。

此外，使用动态包含时，还可以通过 <jsp:param name="xxx" value="xxx" /> 向公共文件中传递参数。

Listener 监听器

Listener（监听器）同 Servlet、Filter（过滤器）一样，是 Java Web 架构中的三大组件之一。

Listener 用于监听某个事件，当该事件发生时，会触发监听器中对应的方法。

监听器分类

监听器有很多分类，但目前最常用的是 ServletContextListener，它用于监听 ServletContext 对象的创建和销毁事件。
