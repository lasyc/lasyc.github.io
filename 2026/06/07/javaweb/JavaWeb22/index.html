什么是 JSON

JSON 是 JavaScript Object Notation 的缩写，中文名称为 JavaScript 对象表示法，是一种轻量级的数据交换格式。它以文本的形式存储和传输数据，具有易于阅读和编写的特点。

  1. 轻量级：早期数据交换使用的是 XML 格式，XML 格式冗长、解析复杂，而 JSON 格式简洁、易于解析
  2. 数据交换：JSON 主要用于客户端和服务器之间的数据交换，特别是在 Web 应用中，JSON 已成为主流的数据格式

JavaScript 对象与 JSON 字符串的转换

JavaScript 中内置了 JSON 对象，提供了两个主要方法：JSON.stringify() 和 JSON.parse()。

  1. JSON.stringify()：将 JavaScript 对象转换为 JSON 字符串
  2. JSON.parse()：将 JSON 字符串解析为 JavaScript 对象
