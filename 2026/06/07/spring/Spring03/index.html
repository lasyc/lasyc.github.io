数组与集合属性注入

数组属性注入

背景：当需要注入的属性是数组类型时，可以使用 <array> 标签来注入。

集合属性注入

背景：当需要注入的属性是集合类型时，可以使用 <list> 标签来注入。

Map 属性注入

背景：当需要注入的属性是 Map 类型时，可以使用 <map> 标签来注入。

引用集合注入

在原有的 List 和 Map 注入基础上，可以先用 <util:list>、<util:map> 标签把集合封装成独立的 Bean，再在需要注入时一次性引用。

  • 如果想在 xml 文件中使用 <util:list> 和 <util:map> 标签，需要在 xml 文件头引入对应的库
