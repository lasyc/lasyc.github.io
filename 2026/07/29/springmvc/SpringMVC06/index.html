Spring MVC 视图

发表于2026-07-29|更新于2026-07-31
|浏览量:

Thymeleaf View

在 Spring MVC 中存在一个 View 接口，所有的视图都必须实现这个接口Spring MVC 支持多种视图实现类，比如 JSP 所需要的 JstlView，以及 Thymeleaf 模板引擎的 ThymeleafView

当我们在 Controller 中返回一个字符串时，Spring MVC 会根据这个字符串去寻找对应的视图默认情况下，Spring MVC 会使用 InternalResourceViewResolver 来解析视图名，这个解析器会将视图名拼接成一个完整的路径，然后交给 ThymeleafView 来渲染

但是如果在字符串中使用 forward: 或 redirect: 前缀，Spring MVC 会将请求转发或重定向到指定的路径，而不是去寻找视图

转发

在 Spring MVC 中，通过返回 forward:/url 的方式可以实现请求的转发转发是服务器内部的操作，浏览器不会感知到请求的变化，URL 地址栏也不会改变

重定向

在 Spring MVC 中，通过返回 redirect:/url 的方式可以实现请求的重定向重定向是服务器告诉浏览器去请求另一个 URL，浏览器会感知到请求的变化，URL 地址栏也会改变

转发和重定向

区别 转发 重定向
浏览器地址栏 不会改变 会改变
请求次数 1次 多次
请求参数 可以共享 不可以共享
请求范围 服务器内部 浏览器端
适用场景 适合在服务器内部跳转 适合跳转到其他网站或应用

视图控制器 view-controller

在 Spring MVC 中，任何的视图都必须通过 Controller 来处理请求并返回视图名但是有些简单的请求，只需要返回一个视图名，而不需要任何业务逻辑处理对于这种情况，Spring MVC 提供了 视图控制器 view-controller 的方式来简化配置
