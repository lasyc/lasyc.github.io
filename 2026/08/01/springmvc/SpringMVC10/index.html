文件上传

Java Web

  1. 必须使用 POST 请求
  2. 必须添加 enctype="multipart/form-data" 属性

MultipartResolver

从 Spring 3.1 开始，Spring 提供了两个 MultipartResolver 的实现用于处理 multipart 请求

  • CommonsMultipartResolver 使用 commons Fileupload 来处理 multipart 请求，所以在使用时，必须要引入相应的jar包
  • StandardServletMultipartResolver 是基于 Servlet3.0 来处理 multipart 请求的，所以不需要引用其他 jar 包，但是必须使用支持 Servlet3.0 的容器才可以（从 Tomcat 7.0.x 的版本开始就支持 Servlet3.0 了）

StandardServletMultipartResolver

在 springmvc-config.xml 配置文件中配置 文件解析器

如果使用 StandardServletMultipartResolver 作为解析器，那么关于文件上传的所有配置都要移到 web.xml 中

如果 web.xml 文件无法识别 multipart-config 等标签，可能是因为头部声明的 servlet 版本太低，需要修改头部声明

使用 StandardServletMultipartResolver 时，如果中文文件名出现乱码，
原因通常是 JVM 默认编码不是 UTF-8（Windows 中文系统默认 GBK）

解决方案：启动 Tomcat 时添加 JVM 参数

CommonsMultipartResolver

如果使用 CommonsMultipartResolver 作为解析器，那么需要添加 commons-fileupload 依赖

对比

对比项 CommonsMultipartResolver StandardServletMultipartResolver
额外依赖 需要 commons-fileupload 不需要
上传参数配置位置 spring-mvc.xml web.xml
中文文件名 defaultEncoding 设为 UTF-8 即可 依赖 JVM 的 file.encoding
最低 Servlet 版本 2.3+ 3.0+
Spring 6+ 已移除 推荐使用

接受文件并保存

同名文件被覆盖（其实不是文件被覆盖，而是文件内容被覆盖了），可以使用时间戳或者 UUID 来区分
