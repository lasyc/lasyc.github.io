MyBatis 历史

MyBatis 最初名为 iBatis，由 Clinton Begin 创建于 2002 年，2009 年加入 Apache 基金会，2010 年 4 月 1 日正式更名为 MyBatis。

MyBatis 是一个优秀的持久层框架，MyBatis 通过 XML 或注解的方式将接口方法调用转化为对数据库的操作，MyBatis 避免了几乎所有的 JDBC 代码和手动设置参数以及获取结果集。

MyBatis 特性

  1. MyBatis 支持自定义 SQL、存储过程以及高级映射。
  2. MyBatis 可以使用简单的 XML 或注解来配置和映射原生信息，将接口方法调用转化为数据库的操作。
  3. MyBatis 可以使用 Java 的 POJO（Plain Old Java Object）来封装数据，支持复杂的映射关系。
  4. MyBatis 避免了几乎所有的 JDBC 代码和手动设置参数以及获取结果集。

MyBatis 和其他持久层技术对比

JDBC

  1. SQL 语句和 Java 代码混合在一起，代码可读性差。
  2. 需要手动处理数据库连接、SQL 执行、结果集处理等，容易出错。
  3. 不支持缓存、延迟加载等高级特性。

Hibernate

  1. 操作简单、开发效率高。
  2. 不支持长、难、复杂的 SQL 语句，性能不如 JDBC。
  3. 内部自动生成 SQL，无法针对性优化。
  4. 基于全映射的全自动框架，不支持部分映射。
  5. 反射操作太多，导致数据库性能下降。

MyBatis

  1. SQL 语句和 Java 代码分离，代码可读性高。
  2. 支持自定义 SQL、存储过程以及高级映射。
  3. 支持缓存、延迟加载等高级特性。
  4. 支持动态 SQL，能够根据条件生成不同的 SQL 语句。
