MyBatis 配置文件详解

MyBatis 的核心配置文件 mybatis-config.xml 中，顶层标签必须严格按 DTD 规定的顺序书写，否则会直接报错。

顺序如下：properties、settings、typeAliases、typeHandlers、objectFactory、objectWrapperFactory、reflectorFactory、plugins、environments、databaseIdProvider、mappers。

environments

properties

在上边的配置文件中，数据库连接信息都是采用硬编码的方式写在配置文件中，我们可以通过 properties 标签来配置数据库连接信息，这样就可以将数据库连接信息从配置文件中分离出来，便于管理和维护。

typeAliases

在编写 MyBatis 的映射文件时，我们通常需要使用 Java 类的全限定名来指定参数类型和返回类型，这样会显得比较冗长。为了简化配置，我们可以使用 typeAliases 标签来为 Java 类指定一个别名，这样在映射文件中就可以直接使用别名来代替全限定名。

mappers

mappers 标签用于配置 MyBatis 的映射文件，通常用于指定映射文件的路径或者指定映射接口的全限定名。
