MyBatis 查询

发表于2026-08-04|更新于2026-08-04
|浏览量:

查询结果为一个对象

如果可以确定查询结果只有一条记录，那么可以使用一个对象来接收，或者使用集合来接收

注意：如果把 SQL 语句中的 WHERE 条件删除，那么查询结果就是多条数据，此时使用一个 User 对象接收就会报错

查询结果为一个集合

当查询结果为多条记录的时候，必须使用集合来接收，上边也演示了，如果使用一个对象接收则会报错

查询结果为一个值

当查询结果为一个值的时候，我们只需要使用简单的数据类型接收就可以了，但是要注意 resultType 的写法，MyBatis 内置了基本数据类型的别名，所以不需要写全类名

别名查询文档

查询结果为一个 Map

Map 其实和实体类的一样的，也就是说只能接收一条记录，以字段名为 key，以返回值为 value

既然如此，那我们也可以使用 List<Map<>> 来接收多条记录

上述案例都是以 Map 本身去存储数据的，但是我们知道 Map 也是集合，那既然如此 Map 该如何保存多条数据呢？我们可以使用 Map 的 value 来保存一条记录，可是 key 该用什么呢？MyBatis 为我们提供了一个注解 @MapKey 用来声明 key，至此我们便可以使用一个 Map 来接收多条记录

总结

返回值记录数 返回值类型
一行一列 一个变量
一行 一个对象、一个 Map、一个集合（对象、Map）
多行 一个集合（对象、Map）、一个 Map（需要使用 @MapKey 声明 key）
