|浏览量:

模糊查询

在模糊查询中，如果直接使用 #{} 来获取参数，将会报错，因为模糊查询自带引号，当占位符处于引号中则无法生效

因为 #{} 使用的是占位符，而且占位符无法生效，那么我们此时就可以使用 ${} 来设置参数，因为它是直接将参数拼接到 SQL 中

亦或者使用 SQL 语句中的拼接函数，总之只要让占位符不要被引号包围，就可以设置参数

再或者这样拼接也可以

批量删除

老师的案例虽然没有成功删除，但是并没有异常，而我这里报错了 Cause: com.mysql.cj.jdbc.exceptions.MysqlDataTruncation: Data truncation: Truncated incorrect DOUBLE value: '1,2,3,4'

原因是因为 #{} 会自动添加 ' 因此 SQL 会变成 IN ('1, 2, 3, 4')，所以无法删除，那么又可以使用 ${}

动态设置表明

在学习 MySql 的时候，我们学习过 分库分表，那么当我们把一条记录保存到不同的表的时候，如果我们想要查询 username 需要到表 1 中，想要插叙 email 又要到表 2 中，此时我们就需要动态的设置表名

不出意外的，使用 #{} 依旧会报错，还是因为拼接式会添加 ' 导致的，因此，依旧使用 ${}

总结

根据上述的案例，我们可以知道，只要在 SQL 中涉及到引号的问题，#{} 都会出问题，此时只能使用 ${} 或者其他一些办法，来让 #{} 不被引号所影响，比如字符串拼接等

添加时返回主键

当我们在添加一条记录后，如果后续的操作需要用到该记录 ID，那么此时就需要在添加数据时获取被添加记录的主键

在原生的 JDBC 中，就有提供对应的方法

而在 MyBatis 中，也为我们提供了对应的方法，只需要在 <insert> 标签中声明 useGeneratedKeys="true" 和 keyProperty="id"
