resultMap

前面在执行查询操作时，我们都是使用 resultType="User"，采用的是默认映射规则，因为那时实体类的属性名和数据库表的字段名是一致的。

但如果出现了不一致的情况，就需要使用 resultMap 来自定义映射规则。

通过测试我们可以发现，所有记录的 empName 和 deptId 都是 null，这是因为数据库中的字段名是 emp_name、dept_id，与 empName、deptId 不一致，因此使用默认映射规则 resultType="Emp" 无法生效。

解决方法一（别名）

解决方法二（mapUnderscoreToCamelCase 配置）

通过上面的案例可以发现，数据库中的字段名统一使用下划线命名，而 Java 中则使用驼峰命名，这并非特例，而是普遍现象。因此 MyBatis 为我们提供了一个配置，可以在字段映射时自动将下划线转为驼峰。

解决方法三（resultMap）

方法二虽然可以解决问题，但前提是数据库字段名和实体类属性名必须满足下划线转驼峰的规则。如果两个字段名之间毫无对应关系，该怎么办呢？此时可以使用 resultMap 来自定义映射规则。

依旧可以生效，记得把配置 mapUnderscoreToCamelCase 注释掉，或者设置为 false。
