SSM 整合

发表于2026-08-08|更新于2026-09-03
|浏览量:

什么是整合

SSM 整合，就是将 Spring、Spring MVC、MyBatis 集成到一个项目中。

  1. Spring 负责框架整体和业务层的事务管理
  2. Spring MVC 负责控制层的请求分发、接收、响应
  3. MyBatis 负责数据库访问层

整合核心问题

一、整合需要几个 IoC 容器

两个容器

前面讲 Spring MVC 全注解配置的时候就说过，一个父容器（Root）和一个子容器（Servlet），到了 Spring Boot 阶段就是一个容器了，这里先不讨论。

使用两个容器也是有好处的：

  1. 两个容器可以各司其职
  2. 解耦
  3. 灵活配置

二、每个容器负责哪些东西

  1. Servlet 容器只负责 Controller
  2. Root 容器负责其它（Service、Mapper、AOP、DataSource、MyBatis 等等）

三、两个容器如何配合

子容器可以"看到"父容器中的 Bean，所以在 Controller 中可以自动注入 Service 对象。

四、一共几个配置类

  1. RootConfig.java 用于配置父容器
  2. ServletConfig.java 用于配置子容器
  3. MyBatisConfig.java 用于配置持久层

五、如何设置配置类

在 Spring MVC 全注解配置的时候讲过，需要创建一个初始化类继承 AbstractAnnotationConfigDispatcherServletInitializer 类，并重写其中的方法来指定父容器配置类和子容器配置类。
