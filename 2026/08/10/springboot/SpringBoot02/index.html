创建主程序

SpringBoot 需要有一个启动类，使用 @SpringBootApplication 注解声明，并在其中编写 main 方法，执行 SpringApplication.run() 方法，传入主类即可

简化配置

SpringBoot 中针对每一项设置都提供了默认的配置，但是如果我们需要修改配置，SpringBoot 也为我们提供了统一的配置方法

只需要在 resources 下创建配置文件 application.properties 即可

配置参考文档

简化部署

SprinBoot 内嵌 Tomcat，所以不需要再打成 war 包后部署，而是直接打成可执行的 jar 包

引入插件

在 maven 命令中找到 package 执行，随后在 target 下生成对应的 jar 包，之后使用命令 java -jar xxxxxxxx.jar 启动即可
