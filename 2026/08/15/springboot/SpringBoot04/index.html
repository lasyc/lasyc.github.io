SpringBoot 配置文件

发表于2026-08-15|更新于2026-08-19
|浏览量:

文件类型

properties

properties 是 SpringBoot 默认的配置文件类型

yaml

简介

SpringBoot 还支持另一种文件类型的配置文件 yaml 或者 yml，它是一种以缩进的标记语言

基本语法

key: value，注意冒号后有空格

数据类型

  1. 一个值

  2. 对象：Obj、Map

  3. 数组：Array、List、Queue

示例

这里可以看到 name=TiAmo，而 TiAmo 是当前电脑的用户名，这是一个非常经典的坑，因为 user.name 是 Spring Boot 的”系统属性占位符”——具体来说，是环境变量优先级高于配置文件导致的。

自动补全

在编写 SpringBoot 所提供的配置时，会有代码提示，但是我们自定义的配置则没有，我们可以引入 spring-boot-configuration-processor，它会在编译阶段，扫描所有的 @ConfigurationProperties 注解，自动生成一个 JSON 文件，当编译器读取到该 JSON 文件时，我们在编写 yml 配置文件时就会提供对应的提示
