Spring Boot 配置文件

发表于2026-08-15|更新于2026-09-12|后端框架Spring Boot
|总字数:638|阅读时长:3分钟|浏览量:

文件类型

properties

properties 是 Spring Boot 默认支持的配置文件类型。

yaml

简介

Spring Boot 还支持另一种格式的配置文件 yaml（后缀也可以是 yml），它是一种以缩进来表示层级结构的标记语言。

基本语法

key: value，注意冒号后面必须有空格。

数据类型

  1. 一个值

  2. 对象：Obj、Map

  3. 数组：Array、List、Queue

示例

这里可以看到 name=TiAmo，而 TiAmo 是当前电脑的用户名。这是一个非常经典的坑：user.name 恰好与 Java 的系统属性 user.name（即当前登录用户名）重名，而系统属性的优先级高于配置文件，所以配置文件中写的 name: Mary 无法覆盖它，最终绑定到的是系统用户名 TiAmo。

自动补全

在编写 Spring Boot 内置的配置项时会有代码提示，但我们自定义的配置项（如上例中的 user）则没有提示。此时可以引入 spring-boot-configuration-processor：它会在编译阶段扫描所有带 @ConfigurationProperties 注解的类，自动生成一个 JSON 文件；编译器读取到该 JSON 文件后，在编写 yml 配置文件时就会提供对应的提示。
