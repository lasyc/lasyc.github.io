@RequestBody

@RequestBody 用于接收请求体中的数据，常见的有两种用法：

  1. 接收原始字符串（请求体是什么就拿到什么）
  2. 接收 JSON 数据并转为 Java 对象（实际开发中最常用）

原理简述：@RequestBody 由 RequestResponseBodyMethodProcessor 解析，底层通过 HttpMessageConverter（消息转换器）将请求体转换为目标对象。JSON 的转换由 Jackson 提供的 MappingJackson2HttpMessageConverter 完成。在 Spring Boot 中，只要引入了 spring-boot-starter-web，就已经内置了 Jackson，无需额外配置。

@RequestBody 与 @RequestParam 的区别：@RequestParam 从 URL 查询参数或表单字段中取值，@RequestBody 从请求体中取值（JSON、XML 等）

@RequestAttribute

@ModelAttribute

@ModelAttribute 有两种用法：

  1. 方法级：标注在 @Controller 的方法上，任意 handler 方法执行前会先执行该方法，并把返回值放入 Model
  2. 参数级：标注在形参上，将请求参数绑定到该对象上（也可以省略不写，Spring 默认就会自动绑定）

注意：方法级 @ModelAttribute 只对当前 Controller 生效，且每次请求都会先执行，若其他 handler 方法也使用同名的 Model 属性，可能会被影响，需留意

@MatrixVariable

@MatrixVariable 是 Spring MVC 中的一个注解，用于从 URL 路径中的矩阵变量（Matrix Variables） 里提取值。

矩阵变量是 URI 规范（RFC 3986）中的一种扩展语法，以 分号 ; 分隔，附加在路径段（path segment）上，如：/colors/red;r=255;g=0;b=0

Spring Boot 默认不会解析矩阵变量，需要通过配置开启：覆写 configurePathMatch，设置 setRemoveSemicolonContent(false)（false 表示不移除路径中的分号内容）。
