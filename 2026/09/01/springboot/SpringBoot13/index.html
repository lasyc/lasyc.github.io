Spring Boot 文件上传

发表于2026-09-01|更新于2026-09-12|后端框架Spring Boot
|总字数:1.6k|阅读时长:6分钟|浏览量:

文件上传

参考文档 - Spring MVC 文件上传

在 Spring MVC 中，要实现文件上传需要自己配置 MultipartResolver（文件解析器）。而在 Spring Boot 中，官方通过自动配置帮我们把 StandardServletMultipartResolver 配好了，所以直接使用 MultipartFile 接收文件即可，无需额外配置。

一次完整的文件上传，主要分为三步：

  1. 页面表单以 POST + multipart/form-data 方式提交
  2. Controller 中使用 MultipartFile 接收文件
  3. 根据业务保存文件（本地磁盘、云存储等）

页面表单

注意事项：

  1. 表单的 method 必须是 post，否则无法上传文件。
  2. 表单的 enctype 必须是 multipart/form-data，否则无法上传文件。
  3. 表单中必须有一个 input 标签，且 type 必须是 file，否则无法上传文件。

单文件上传

需要使用 MultipartFile 类型来接收上传的文件。

几点说明：

  • @RequestPart("file") 与 @RequestParam("file") 都可以接收 MultipartFile，注解里的值要和前端表单 input 的 name 一致
  • multipart 支持默认就是开启的（spring.servlet.multipart.enabled=true），不需要额外配置即可接收文件
  • transferTo() 是最常用的保存方式，底层会帮我们把临时文件移动到目标位置

MultipartFile 常用方法

方法 说明
getOriginalFilename() 获取客户端上传时的原始文件名
getName() 获取表单中字段的 name 值（如 file）
getSize() 获取文件大小（字节）
getContentType() 获取文件的 MIME 类型（如 image/png）
isEmpty() 判断是否未选择文件
transferTo(File) 把上传的文件保存到目标位置（最常用）
getInputStream() 获取输入流，自行读写

多文件上传

将参数类型改为 MultipartFile[] 或 List<MultipartFile>，前端放多个同名 input 即可。

解决文件重名问题

直接使用原始文件名保存，如果两个用户上传了同名文件，后上传的会覆盖先上传的。通常的做法是用 UUID（或时间戳）生成唯一文件名：

原理

Spring Boot 帮我们自动配置了 StandardServletMultipartResolver，该类实现了 MultipartResolver 接口，用于解析 multipart/form-data 类型的请求。

DispatcherServlet#doDispatch() 在处理请求时会先调用 checkMultipart()：如果请求是 multipart 类型，就交给 MultipartResolver 解析，把普通请求包装成 MultipartHttpServletRequest，之后 Controller 才能把文件绑定到 MultipartFile 参数上。这个解析过程对我们是透明的。

在 Spring MVC 时代，MultipartResolver 有两个实现可以选择：

  • CommonsMultipartResolver：基于 commons-fileupload，需要额外引入 jar 包（Spring 6 已移除）
  • StandardServletMultipartResolver：基于 Servlet 3.0 规范，无需额外依赖

注意事项

  1. 表单 method 必须是 post，enctype 必须是 multipart/form-data
  2. 前端 input 的 name 要和 Controller 参数名（或 @RequestPart 的值）一致
  3. 文件超过 max-file-size / max-request-size 时会抛出异常，可以通过全局异常处理器统一处理
  4. 保存文件时建议用 UUID 重命名，避免同名覆盖、中文文件名乱码等问题
  5. 不要直接写死磁盘路径，也不要保存到 target 等部署目录下（重新打包会丢失），实际项目建议使用配置项或云存储（如 OSS）
  6. 上传后的文件无法直接通过 URL 访问，如果需要预览 / 下载，可以单独写下载接口（参考 Spring MVC 文件下载），或者把上传目录映射为静态资源路径

总结

  • Spring Boot 通过 MultipartAutoConfiguration 自动配置了 StandardServletMultipartResolver，文件上传开箱即用
  • 后端使用 MultipartFile 接收文件，通过 transferTo() 保存
  • 文件大小、请求大小等限制通过 spring.servlet.multipart.* 配置
  • 学习时先跑通”上传 -> 保存”，再逐步考虑文件名策略、存储位置、云存储等进阶方案
