JDBC 数据库连接池
数据库连接池在前面的学习中，每次执行 SQL 时都需要创建、关闭连接，因此频繁创建、关闭连接也会带来一定的性能损耗。类似于线程池的思路，这里引入数据库连接池：提前创建好一定数量的数据库连接对象，每次使用时从池中取出，用完再放回池中，避免频繁创建、关闭连接 开源数据库连接池 DBCP：Apache 提供的数据库连接池，Tomcat 内置使用（Tomcat 8 起为基于 DBCP 的 dbcp2），早期应用广泛，目前仍在维护 C3P0：早期流行的开源连接池，配置灵活（支持 XML 配置），但版本更新缓慢，新项目已较少使用 Proxool：SourceForge 提供的数据库连接池，支持连接池状态监控，但项目已停止维护多年 BoneCP：早期以性能著称的数据库连接池，同样已停止维护 Druid：阿里巴巴开源的数据库连接池，功能全面（自带监控统计、慢 SQL 日志、防 SQL 注入等），国内使用非常广泛 补充：除了上面的老牌连接池，目前 Java 生态中主流的还有 HikariCP（Spring Boot 默认内置，轻量且性能极佳）与 Druid。下文以 C3P0、DBCP、Drui...
