Spring Boot Actuator

中文文档

等学到微服务之后，每个服务都会被部署在一台服务器上，为了方便监控每个服务的运行状态，Spring Boot 提供了一个场景依赖 Actuator

使用

引入依赖

启动项目后访问 http://localhost:8080/actuator，返回结果是我们可以查看的指标，每个路径对应一个指标，只需要访问对应的路径即可

访问 http://localhost:8080/actuator/health（下面为了便于理解，在 JSON 中加了注释，实际返回的是标准 JSON，不会包含注释）

除此之外还有很多端点，但默认没有暴露，需要我们自己配置后才能访问，这些端点的路径格式都是 http://localhost:8080/actuator/ + 端点 id

Endpoints

默认情况下，端点的暴露方式有两种：

  1. JMX：暴露所有端点（Endpoints）
  2. Web：只暴露 health 和 info

因此，如果我们想通过浏览器查看所有 Endpoints，就需要在配置文件中开启配置

再次访问 http://localhost:8080/actuator

Endpoints

端点 地址 说明
self /actuator Actuator 根路径，列出所有可用端点
health /actuator/health 应用健康状态
health-path /actuator/health/{*path} 指定健康分组详情（如 liveness、readiness）
info /actuator/info 应用自定义信息
beans /actuator/beans 所有 Spring Bean 及依赖关系
conditions /actuator/conditions 自动配置条件评估报告（为什么生效/未生效）
configprops /actuator/configprops 所有 @ConfigurationProperties 属性
configprops-prefix /actuator/configprops/{prefix} 按前缀过滤配置属性
env /actuator/env 所有环境变量和属性
env-toMatch /actuator/env/{toMatch} 按名称查询环境变量
loggers /actuator/loggers 所有 Logger 及级别
loggers-name /actuator/loggers/{name} 查看/动态修改指定 Logger 级别
metrics /actuator/metrics 所有可用指标名称列表
metrics-requiredMetricName /actuator/metrics/{requiredMetricName} 指定指标详情（如 jvm.memory.used）
mappings /actuator/mappings 所有 URL 映射（Controller 路由）
threaddump /actuator/threaddump 线程快照（类似 jstack）
scheduledtasks /actuator/scheduledtasks 定时任务列表
sbom /actuator/sbom 软件物料清单（依赖清单）
sbom-id /actuator/sbom/{id} 指定 SBOM 详情
