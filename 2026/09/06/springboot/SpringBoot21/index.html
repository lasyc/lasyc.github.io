JUnit 5

中文文档

JUnit 5 = JUnit Platform + JUnit Jupiter + JUnit Vintage

  • JUnit Platform 作为 在 JVM 上启动测试框架 的基础。它还定义了 TestEngine API，用于开发在平台上运行的测试框架。此外，该平台还提供了一个 控制台启动器，用于从命令行启动平台，以及 JUnit Platform Suite Engine，用于使用平台上的一个或多个测试引擎运行自定义测试套件。流行的 IDE（参见 IntelliJ IDEA、Eclipse、NetBeans 和 Visual Studio Code）和构建工具（参见 Gradle、Maven 和 Ant）也对 JUnit Platform 提供了第一流的支持。

  • JUnit Jupiter 是 编程模型 和 扩展模型 的组合，用于在 JUnit 5 中编写测试和扩展。Jupiter 子项目提供了一个 TestEngine，用于在平台上运行基于 Jupiter 的测试。

  • JUnit Vintage 提供了一个 TestEngine，用于在平台上运行基于 JUnit 3 和 JUnit 4 的测试。它需要 JUnit 4.12 或更高版本存在于类路径或模块路径中。

常用注解

中文文档

@DisplayName

@DisplayName 用于为该测试类或这个方法起名字，在执行测试代码时，控制台可以显示当前测试类或测试方法的名字

@BeforeEach

@BeforeEach 用于在每一个测试方法之前，执行被注解声明的方法

@AfterEach

@AfterEach 同理

@BeforeAll

@BeforeAll 用于在每一个测试类之前，执行被注解声明的方法

@AfterAll

@AfterAll 同理

@Disabled

@Disabled 用于声明当前测试方法不执行

@Timeout

@Timeout 用于声明当前方法的最大执行时间、超出时间抛出异常

@RepeatedTest

@RepeatedTest 用于让当前测试方法多次执行

Spring BootTest

@Spring BootTest 用于让当前的测试类获取 Spring 中的功能，如：自动注入

断言（Assertions）

中文文档

断言其实就是一种判断方法，用于检查结果是否与预期一致

断言方法

简单断言

用来对单个值进行简单的验证。如：

方法 说明
assertEquals 判断两个对象或两个原始类型是否相等
assertNotEquals 判断两个对象或两个原始类型是否不相等
assertSame 判断两个对象引用是否指向同一个对象
assertNotSame 判断两个对象引用是否指向不同的对象
assertTrue 判断给定的布尔值是否为 true
assertFalse 判断给定的布尔值是否为 false
assertNull 判断给定的对象引用是否为 null
assertNotNull 判断给定的对象引用是否不为 null

数组断言

组合断言

多个断言必须同时成立

异常断言

用于断言执行某段代码会抛出指定类型的异常，若未抛出或类型不符则测试失败

超时断言

快速失败

不进行任何断言，单纯的想让测试结束，也可以配合条件判断使用

假设（Assumptions）

假设并不是用来判断方法的执行结果的，而是用来判断当前方法是否满足执行条件

参数化测试（@ParameterizedTest）

中文文档

注解 描述
@ValueSource 是最简单的源之一。它允许您指定一个文字值数组，并且只能用于为每次参数化测试调用提供单个参数。
@NullSource 为带注解的 @ParameterizedTest 方法提供单个 null 参数。
@EmptySource 为以下类型的参数的带注解的 @ParameterizedTest 方法提供单个空参数：java.lang.String、java.util.Collection（以及具有 public 无参数构造函数的具体子类型）、java.util.List、java.util.Set、java.util.SortedSet、java.util.NavigableSet、java.util.Map
@NullAndEmptySource 一个组合注解，它结合了 @NullSource 和 @EmptySource 的功能。
@EnumSource 提供了一种使用 Enum 常量的便捷方法
@CsvFileSource 指定一个 CSV 文件作为参数
@MethodSource 指定一个方法的返回值作为参数
@FieldSource 允许您引用测试类或外部类的一个或多个字段。
