Spring Security 介绍

发表于2026-09-07|更新于2026-09-12|后端框架Spring Security
|总字数:594|阅读时长:1分钟|浏览量:

Spring Security

Spring Security 是 Spring 官方出的安全框架，前身是 Acegi Security。前面那篇（Spring Security 6）已经贴过官网那段介绍了，这里不重复，只记几个后面对比时会用到的点：

  • 走的是过滤器链，和 Spring 生态（Boot / MVC / Cloud）集成最顺，加个 spring-boot-starter-security 依赖就能生效
  • 功能最全：认证、授权、CSRF 防护、Session 管理、方法级安全，OAuth2 / OIDC 也是内置的
  • 代价是概念多、配置复杂、学习曲线陡，但正因为用的人多，网上资料也最多

常见的认证框架

做认证授权的 Java 框架，除了 Spring Security，常见的还有下面两个，我先把三个都过一遍再决定学哪个。

Apache Shiro

Apache 出的轻量级安全框架，核心是 Subject（当前用户）、SecurityManager（安全管理器）、Realm（从数据源拿用户/权限）。

  • 上手比 Spring Security 简单，没有那一大串过滤器要理解
  • 认证、授权、会话管理都内置，文档还算齐全
  • 但没有官方 Spring Boot 整合，要自己拼 starter 或者用第三方的
  • 功能深度不如 Spring Security，OAuth2 这类基本要自己接

Sa-Token

国产开源框架，主打轻量、简单，中文文档友好。

  • 登录认证、权限认证、Session 会话、踢人下线这些都有，配置很少
  • 官方提供 sa-token-spring-boot3-starter 之类的整合包，跑起来很快
  • 社区活跃、案例多，但生态规模和资料量还是比不过前两个

对比

维度 Spring Security Apache Shiro Sa-Token
出身 Spring 官方 Apache 国产开源
上手难度 陡 平缓 平缓
Spring Boot 整合 官方 starter，开箱即用 无官方整合，靠第三方 官方整合包
功能范围 最全（OAuth2 / CSRF / 方法安全等） 认证授权会话为主 认证授权会话为主
社区与资料 最多 一般 中文资料多

我为什么选 Spring Security

理由很直白：

  1. 我一直在学 Spring Boot 生态，它是官方默认方案，spring-boot-starter-security 加进 pom 就能用，跟着 Spring 版本走，不用自己适配；
  2. 后面大概率会碰 OAuth2、前后端分离 JWT 这些，它都覆盖，免得学到一半换框架；
  3. 虽然难，但踩坑了搜得到答案。

所以这个系列就用它了，03 开始动手写代码。
