访问资源

打开浏览器输入地址 http://localhost:8080/ 会自动跳转到 http://localhost:8080/login 页面，这是因为 Spring Security 已经开始工作了，当用户访问资源时，Spring Security 会通过过滤器的方式来判断用户是否认证，如果没有则会跳转至自己的认证页面。

认证页面的默认账号为 user，而密码则可以查看控制台，每次项目启动时 Spring Security 都会生成一个密码并打印在控制台 Using generated security password: 658426da-1b99-4ca9-a079-a4a76e1d495c

登录认证后，Spring Security 会生成一个 Session 并通过 Cookie 保存在浏览器端，如果删除该 Cookie 则需要重新认证

原理分析

Spring Security 的原理其实就是一系列的过滤器链，其中内置了很多种类的过滤器，职责也各不相同

Spring Security 默认过滤器链大约有 15~17 个过滤器（视版本和配置略有不同），按执行顺序如下：

# 过滤器 职责
1 DisableEncodeUrlFilter 禁止将 Session ID 编码到 URL 中，防止会话固定攻击
2 WebAsyncManagerIntegrationFilter 将 SecurityContext 与 Spring 异步请求处理集成
3 SecurityContextHolderFilter 请求前从 SecurityContextRepository（默认 HttpSession）加载上下文，请求后保存（Security 6 起由 SecurityContextPersistenceFilter 更名）
4 HeaderWriterFilter 向响应写入安全头（X-Content-Type-Options、Cache-Control、X-Frame-Options 等）
5 CorsFilter 处理跨域预检请求（OPTIONS）及 CORS 头
6 CsrfFilter CSRF 防护，校验 Token
7 LogoutFilter 匹配登出路径，执行登出逻辑（清除 Session、清理上下文等）
8 UsernamePasswordAuthenticationFilter 拦截表单登录，提取账号密码进行认证
9 DefaultLoginPageGeneratingFilter 未自定义登录页时，自动生成默认登录页面
10 DefaultLogoutPageGeneratingFilter 未自定义登出页时，自动生成默认登出页面
11 BasicAuthenticationFilter 处理 HTTP Basic 认证，解析 Authorization: Basic … 头
12 RequestCacheAwareFilter 登录成功后恢复之前被缓存的请求（跳转回原来想访问的页面）
13 SecurityContextHolderAwareRequestFilter 包装原始请求，使 request.isUserInRole() 等方法可用
14 AnonymousAuthenticationFilter 如果前面没有认证成功，则构造一个匿名身份
15 SessionManagementFilter 会话管理：会话固定保护、并发登录控制等
16 ExceptionTranslationFilter 捕获后续过滤器抛出的认证/授权异常，交给 AuthenticationEntryPoint 或 AccessDeniedHandler 处理
17 AuthorizationFilter 最终的授权决策，判断已认证用户是否有权限访问当前资源

上面这张表是网上常见的 17 个版本，不过版本不同数量会有出入——我在这套 Boot 4.x / Security 6 上断点实测只有 16 个（见下文 doFilterInternal 里的调试信息）：没有 CorsFilter、SessionManagementFilter，多了一个 DefaultResourcesFilter，第 3 个也已经更名成 SecurityContextHolderFilter，所以数量不用死记

所以，Spring Security 的核心就是一条有序的过滤器链，链路挂在 FilterChainProxy 这个入口下面

  1. 这 16/17 个里只有少数是核心过滤器，其余大多是按需装配出来的
  2. 执行顺序自上而下，响应则自下而上，未通过安全校验的请求会被拦截
  3. 想要查看过滤器链执行顺序，则可以开启 debug 模式

FilterChainProxy 是所有过滤器的入口，其中含有一个 doFilter 方法，我们可以在此打个断点

默认登录页和退出页，有默认的 HTML 模板，是字符串形式，通过 HttpServletResponse 写到页面上
