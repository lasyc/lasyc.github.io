UserDetailsService 接口

根据上面的源码，一切认证的基础都是基于 loadUserByUsername 方法构建出的 User 信息，因此如果想自定义认证逻辑，就需要实现 UserDetailsService 接口的 loadUserByUsername 方法

这里的 loadUserByUsername 方法需要返回一个 UserDetails 对象，但是源码中返回的是 User 对象，这是因为 User 是 UserDetails 的实现类

当然如果我们有其他特殊要求，也可以自定义 User 类实现 UserDetails 接口，或者继承 User 类，来进行扩展和定制
