启动项目并访问 http://localhost:8080/ 依旧是跳转至 http://localhost:8080/login 输入账号密码，会发现控制台报错

这是因为 Spring Security 在校验密码的时候，需要使用加密算法，因此我们的密码，需要包含一个前缀来告诉 Security 我们的密码使用了哪个加密方式，并且提供一个默认编码器

密码加密（PasswordEncoder 接口）

Spring Security 强制要求密码必须被加密存储，并且 Security 提供了很多的加密方式（实现类），这些实现类都是 PasswordEncoder 的实现类

常用的密码加密器（具体可使用 Ctrl + H 快捷键查看全部实现类）：

BCryptPasswordEncoder 是最常用也是官方推荐使用的加密器

编写测试代码

BCryptPasswordEncoder 每次对密码进行加密时，都会生成一个随机盐值，这个盐值会与密码混合后在进行哈希计算，因此同一段密码加密后的结果每次都不一样

盐值是一段随机的二进制/字符串类型（BCrypt 中固定 16 字节，即 128 位），其作用就是为了防止同一段密码加密后的结果一致

如果没有盐值，同一段密码，加密后的结果一致，攻击者只需要破解其中一个，就相当于破解了同密码的所有用户，而有了盐值，即使密码相同，加密后的结果也不同
