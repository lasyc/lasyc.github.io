退出登录

Spring Security 会自动拦截 /logout 的请求，实现退出登录功能

修改 success.html 页面，添加退出按钮

登录成功后会跳转至 success.html 页面，然后点击 Logout 按钮即可回到 login.html 页面

这里能用 GET 请求退出，是因为前面把 CSRF 关掉了。CSRF 开启时 LogoutFilter 只认 POST 请求，用 GET 是不生效的

同理，我们也可以修改退出登录的请求路径

对应 HTML 中的 action 也要修改

负责退出登录的过滤器为 LogoutFilter
