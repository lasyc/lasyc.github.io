Spring Security 基于注解的访问控制

发表于2026-09-11|更新于2026-09-12|后端框架Spring Security
|总字数:428|阅读时长:1分钟|浏览量:

注解

上一章节学习基于权限的访问控制和基于角色的访问控制时，我们需要在配置类中将请求路径和权限标识符一一匹配，每加一个路径就要写一个 requestMatchers，繁琐且不便于维护

因此，Spring Security 为我们提供了一些注解，只需要把注解加到对应的控制器方法上，便可实现访问控制

注解介绍

  1. @EnableGlobalMethodSecurity：开启全局基于注解的权限控制（新版使用 @EnableMethodSecurity）
  2. @PreAuthorize：在方法执行前判断权限
  3. @PostAuthorize：在方法执行后判断权限

在控制器的方法上添加注解，如果注解添加到类上面，则对所有方法生效
