完整示例

sec:authorize

sec:authorize — 权限判断表达式，当表达式结果为 true 时才会显示标签

认证状态

表达式 说明
isAuthenticated() 是否已认证（已登录）
isAnonymous() 是否为匿名用户（未登录）
isRememberMe() 是否通过”记住我”登录
isFullyAuthenticated() 是否完整登录（非记住我）
isAuthenticated() && !isRememberMe() 同上，等价写法

角色 / 权限

表达式 说明 示例
hasRole(‘X’) 是否拥有某个角色（自动加 ROLE_ 前缀） hasRole(‘ADMIN’)
hasAnyRole(‘X’,’Y’) 是否拥有任意一个角色 hasAnyRole(‘ADMIN’,’USER’)
hasAuthority(‘X’) 是否拥有某个权限（不加前缀，精确匹配） hasAuthority(‘user:read’)
hasAnyAuthority(‘X’,’Y’) 是否拥有任意一个权限 hasAnyAuthority(‘user:read’,’user:write’)

其他

表达式 说明
hasIpAddress(‘192.168.1.0/24’) 是否来自指定 IP / 网段

sec:authentication、

sec:authentication — 获取认证对象属性，用于显示认证对象信息

Authentication 根级属性

表达式 返回类型 说明
name String 用户名（getName()）
principal Object 主体对象（通常是 UserDetails）
credentials Object 凭据（登录后通常为 null）
authorities Collection<GrantedAuthority> 所有权限集合
details Object 认证详情（通常是 WebAuthenticationDetails）
authenticated boolean 是否已认证

principal 嵌套属性（UserDetails 默认实现）

表达式 返回类型 说明
principal.username String 用户名
principal.password String 密码（数据库中的，BCrypt 加密后的）
principal.authorities Collection<GrantedAuthority> 权限集合
principal.enabled boolean 账号是否启用
principal.accountNonExpired boolean 账号是否未过期
principal.accountNonLocked boolean 账号是否未锁定
principal.credentialsNonExpired boolean 凭据是否未过期

details 嵌套属性（WebAuthenticationDetails）

表达式 返回类型 说明
details.remoteAddress String 客户端 IP 地址
details.sessionId String Session ID

OAuth2 登录场景

表达式 说明
principal.name OAuth2 用户标识
principal.attributes.email OAuth2 返回的邮箱
principal.attributes.name OAuth2 返回的名称
principal.attributes.picture 头像 URL
principal.attributes 所有属性的 Map
