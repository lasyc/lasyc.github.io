Vue 简介

Vue 是什么

Vue 是一款用于构建用户界面的 JavaScript 框架。它基于标准 HTML、CSS 和 JavaScript 构建，并提供了一套声明式的、组件化的编程模型，帮助你高效地开发用户界面。无论是简单还是复杂的界面，Vue 都可以胜任。

谁开发的

略

Vue 的特点

  1. 组件化开发，提高代码复用率
  2. 声明式编码，无需直接操作 DOM
  3. 使用虚拟 DOM

学习 Vue 需要掌握 JS 知识

  • ES6 语法规范
  • ES6 模块化
  • 包管理器
  • 原型、原型链
  • 数组常用方法
  • Axios
  • Promise
