Advisor

Advisor 是一个接口，用于在向 AI 大模型发送请求之前或者之后，对请求和响应进行拦截，其子接口分别为：

  1. MemoryAdvisor
  2. CallAdvisor
  3. ToolAdvisor
  4. StreamAdvisor

上述四个仍是接口，不过已经可以看出大致的分类，再往下就是具体的实现了。其中 CallAdvisor 对应阻塞式调用，StreamAdvisor 对应流式调用，大多数实现类会同时实现这两个接口：

  1. SimpleLoggerAdvisor：打印请求/响应日志，调试神器，性能开销最小，生产可关。
  2. MessageChatMemoryAdvisor：把历史对话以 Message 列表形式注入 prompt（最常用，最忠实于原始消息角色）。
  3. ToolCallingAdvisor：把已注册的 ToolCallback 织入调用链并驱动多轮工具调用。
  4. StructuredOutputValidationAdvisor：配合结构化输出使用，对模型输出做 JSON Schema 校验，不通过就带上错误反馈重试（默认最多 3 次）或抛异常。
  5. SafeGuardAdvisor：基于关键词/规则做敏感词拦截，命中直接短路返回预设文案，不调模型。
  6. ChatModelCallAdvisor/ChatModelStreamAdvisor：把 ChatModel 适配成 Advisor，处在链尾真正发起请求。这是框架内部用的，一般不自己实例化，但你在调试链路日志时会看到它们。
需要什么 用哪个
打印调试日志 SimpleLoggerAdvisor
多轮记忆 MessageChatMemoryAdvisor（配 ChatMemory）
调用工具 ToolCallingAdvisor（通常自动装配）
结构化输出校验 StructuredOutputValidationAdvisor
敏感词拦截 SafeGuardAdvisor
自己写拦截逻辑 实现 BaseAdvisor
自己写记忆策略 实现 BaseChatMemoryAdvisor
