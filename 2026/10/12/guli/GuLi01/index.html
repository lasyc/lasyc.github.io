谷粒学院 Day 01

发表于2026-10-12|更新于2026-10-19|后端项目实战谷粒学院
|总字数:742|阅读时长:2分钟|浏览量:

项目背景

随着知识付费观念的普及和互联网技术的发展，在线教育市场规模持续扩大，用户对优质教育资源的需求日益增长

谷粒学院是一个 B2B2C 模式的在线教育平台：

  1. 前台（用户端）：浏览课程、观看视频、下单支付
  2. 后台（管理端）：管理员运营平台，教育机构（商家）管理课程和教师

项目采用前后端分离 + 微服务架构，通过实现一个完整的在线教育产品，综合运用 Spring Boot、Spring Cloud、MyBatis-Plus 等技术

商业模式

  1. C2C：个人对个人，平台只提供交易场所（如淘宝二手）
  2. B2C：企业对个人，平台自营（如京东自营），角色有管理员、普通用户
  3. B2B2C：企业对企业对个人，平台引入商家入驻（如天猫、美团），角色有管理员、普通商家、普通用户

谷粒学院采用的是 B2B2C 模式

功能模块

系统按角色划分功能模块，不同角色使用的功能不同，主要分为管理员（后台）和用户（前台）两部分

管理员

  1. 教师管理模块
  2. 课程分类管理模块
  3. 课程管理模块
  4. 统计分析模块
  5. 订单管理模块
  6. Banner 管理模块（轮播图、幻灯片）
  7. 权限管理模块

用户

  1. 首页
  2. 教师列表、详情
  3. 课程列表、详情（视频在线播放）
  4. 登录、注册（支持微信、QQ登录）
  5. 支付功能

技术栈

  1. 前端：

    • Vue：渐进式前端框架
    • Element UI：基于 Vue 的 UI 组件库
    • Axios：发起 HTTP 请求的库

  2. 后端：

    • Spring Boot：快速构建 Spring 应用
    • Spring Cloud：微服务治理（注册中心、网关、远程调用等）
    • Spring Security：认证与授权
    • MyBatis-Plus：持久层框架，简化数据库操作
    • Redis：缓存，减轻数据库压力
    • Maven：项目构建与依赖管理
    • EasyExcel：Excel 的导入导出（如课程分类导入）
    • JWT：无状态的身份令牌
    • OAuth2：第三方登录授权（微信、QQ）

  3. 其他：

    • 阿里云 OSS：对象存储，存放图片等静态资源
    • 阿里云视频点播：视频的上传与在线播放
    • 阿里云短信：发送手机验证码
    • 微信支付、登录：第三方支付与登录
    • Docker：容器化部署
    • Git：版本控制
    • Jenkins：持续集成 / 持续部署

MyBatis-Plus 学习

MyBatis-Plus（简称 MP）是在 MyBatis 基础上增强的持久层框架，只做增强不改变原有功能，目的是简化开发、提高效率

主要特性：

  1. 内置通用 Mapper 和 Service，单表 CRUD 开箱即用
  2. 条件构造器（QueryWrapper / LambdaQueryWrapper），支持各种复杂查询
  3. 内置分页插件、逻辑删除、自动填充、乐观锁等常用功能
  4. 代码生成器，根据数据库表逆向生成 Entity、Mapper、Service、Controller

后续通过教师管理模块的开发来学习 MyBatis-Plus 的具体使用
