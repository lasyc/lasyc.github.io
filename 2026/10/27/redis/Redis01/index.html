初识 Redis

认识 NoSQL

在前面我们学习了 MySQL，MySQL 属于关系型数据库，而 Redis 则属于非关系型数据库，我们称之为 NoSQL

区别 关系型数据库 非关系型数据库
数据结构 结构化 非结构化
数据关联 关联的 无关联的
查询方式 SQL 专属查询语句
事务特性 ACID BASE
存储方式 磁盘 内存
扩展性 垂直 水平

认识 Redis

Redis 全程 Remote Dictonary Server，意为远程词典服务器，是一个基于内存的键值对型 NoSQL 数据库

  1. 键值对型：value 支持多种不同的数据结构
  2. 单线程：每个命令具备原子性
  3. 低延迟、速度快：基于内存，IO 多路复用、良好的编码
  4. 支持数据持久化
  5. 支持主从集群、分片集群
