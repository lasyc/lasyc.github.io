Vue 是什么

Vue (发音为 /vjuː/，类似 view) 是一款用于构建用户界面的 JavaScript 框架。它基于标准 HTML、CSS 和 JavaScript 构建，并提供了一套声明式的、组件化的编程模型，帮助你高效地开发用户界面。无论是简单还是复杂的界面，Vue 都可以胜任。

插值表达式

插值表达式 {{}}，可以将 Vue 实例中的变量或表达式渲染到页面中

Vue 响应式特性

在 Vue 实例中声明的变量，都具备响应式特性，即当变量的值发生改变时，与之相关的内容会同步刷新，重新计算或渲染

打开文件后，点击 F12 打开开发者工具，在控制台执行 vm.message = 'Hello Java'修改变量 message 的值，会发现页面中的 Hello Vue 变成了 Hello Java

由此我们可以知道，Vue 其实会在底层监听数据的变化，当数据变化时，会重新渲染 DOM

Vue 指令

Vue 指令是 Vue 内部提供的一些指令，格式为 v-指令，通过这些指令，我们可以实现更多的功能，与插值表达式不同的是，Vue 指令实在标签内部使用的，如：<div v-html="message"></div>，和class、style这些标签属性使用类似

v-html

v-html 用于将变量内容以 HTML 的形式渲染到视图中

v-show

v-show 用于控制元素的显示/隐藏，需要传入一个布尔表达式，结果为 true 时显示，反之不显示，虽然没有显示，但是 DOM 元素是存在的，只是添加了 display: none; 所以看不到而已，适合频繁的切换场景，没有操作 DOM 的性能开销

v-if、v-else 和 v-else-if

v-if 同样用于控制元素的显示/隐藏，需要传入一个布尔表达式，结果为 true 时显示，反之不显示，与 v-show 不同的是 DOM 元素是不存在的，不适用于频繁的切换场景
