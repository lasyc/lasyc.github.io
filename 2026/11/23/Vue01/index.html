Vue 是什么

Vue (发音为 /vjuː/，类似 view) 是一款用于构建用户界面的 JavaScript 框架。它基于标准 HTML、CSS 和 JavaScript 构建，并提供了一套声明式的、组件化的编程模型，帮助你高效地开发用户界面。无论是简单还是复杂的界面，Vue 都可以胜任。

插值表达式

Vue 响应式特性

在 Vue 实例中声明的变量，都具备响应式特性，即当变量的值发生改变时，与之相关的内容会同步刷新，重新计算或渲染

由此我们可以知道，Vue 其实会在底层监听数据的变化，当数据变化时，会重新渲染 DOM

Vue 指令

Vue 指令是 Vue 内部提供的一些指令，格式为 v-指令，通过这些指令，我们可以实现更多的功能，与插值表达式不同的是，Vue 指令实在标签内部使用的，如：<div v-html="message"></div>，和class、style这些标签属性使用类似

v-html

v-html 指令用于更新元素的 innerHTML，将内容作为原始 HTML 渲染。

v-html 实例

v-show

v-show 指令根据绑定表达式的真假值来决定元素是否显示。无论条件为真还是为假，元素都会渲染到 DOM 中，只是通过 CSS 控制其可见性。

v-show 实例

v-if、v-else 和 v-else-if

v-if 指令会根据绑定表达式的真假值有条件地渲染元素。当条件为真时，元素会被渲染到 DOM 中；当条件为假时，元素不会被渲染。

v-if 实例

v-else、v-else-if 实例

v-else 和 v-else-if 这里不多赘述，逻辑同 Java 中的 if…eles if…else… 一样

v-show 与 v-if 的区别

特性 v-show v-if
渲染方式 始终渲染到 DOM，只是控制显示/隐藏 条件为真时渲染，为假时不渲染
切换性能 切换开销小（只改 CSS） 切换开销大（需要创建/销毁元素）

v-on 指令用于为元素绑定事件处理函数。可以用它来监听原生 DOM 事件，也可以监听自定义组件发出的事件。
